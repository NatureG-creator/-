# 腐蚀研究工作台

专业中文本机研究网站，连接“实测点云 → MATLAB六指标 → 单/多阶段CA–GA模拟”。网页实际启动本机计算程序，支持完整调参、文件检查、随机种子、进度、严格模式恢复、过程图与数值下载。

GitHub保存源码；计算服务运行在使用者自己的电脑上。直接浏览GitHub文件或静态页面不能启动本机MATLAB/Python。

## 一键打开

1. 安装Python，在本目录安装严格模式依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

2. 双击 **`打开网站.cmd`**。脚本寻找Python、检查依赖、后台启动并打开浏览器；已启动时复用服务，端口占用时选择附近空闲端口。
3. 手动启动可运行：

   ```powershell
   python start_server.py --port 8523
   ```

   打开 `http://127.0.0.1:8523/`。只允许本机访问。运行记录和日志存入`.runtime/`，不要删除需要恢复的任务目录。

## 第一部分：实测点云六指标

- 上传参考扫描和其局部XYZ子集。支持TXT、CSV、TSV、XYZ，前三列为X/Y/Z有限数值，单位mm。预览实际点数、范围、采样图与读取时间。
- 不限制为60或190 mm；参考区列数、中央腐蚀区列数、裁边和网格间距可调整。文件必须满足原子集及齐平规则，不能把独立扫描默认为同一物理参考面。
- 从`matlab/step00_corrosion_config.m`生成完整参数目录；布尔值、数组、枚举均按真实类型提交。输入输出路径由独立任务管理，避免覆盖原实验数据。
- 六指标、原坑样本、MAT/CSV/Excel、图像和可用的APDL点云文本保存到本次任务outputs。物理校准状态不成立时可下载诊断，但不能把它作为有效模拟目标。
- 点云任务额外生成 `timing.json`，拆分输入读取、MATLAB 进程、脚本预处理/形貌分析/数值与图片导出、后处理与总耗时；预检报告重复点和零跨度坐标轴。MATLAB 脚本分项计时以 `matlab_timing.json` 为准。
- 模拟结果记录运行环境、Git commit 和主进程观测峰值内存；多工况支持整批停止、失败工况检查点重试与 ZIP 打包下载。
- 提速边界与基准验收方法见 [`docs/2026-10-14-性能优化建议.md`](docs/2026-10-14-性能优化建议.md)，严格模式结果一致性要求保持不变。
- 安装MATLAB，并使`matlab`可从PATH调用，或设置：

  ```powershell
  $env:MATLAB_BIN = 'C:\Program Files\MATLAB\R2024b\bin\matlab.exe'
  ```

  原脚本使用`imgaussfilt`、`watershed`、`normfit`等函数，需要匹配的图像处理和统计工具箱。网站检查可执行文件，具体许可证与工具箱由MATLAB日志确认。

## 第二部分：单/多阶段模拟

- 完整目录来自`engine/01_运行程序与数据/unified_config.py`。每项附标签、作用和适用范围；材料拟合等后续字段可以保存，但当前CA/GA不会使用它们。
- 输入MAT、CSV、TXT、TSV、XLSX或手动N×6矩阵。MAT自动列出变量和行列，XLSX读取当前工作表并允许首行文字表头；可选择按行N×6或按列6×N，6×6需要明确方向。支持普通v7 MAT，v7.3需另存v7或六列CSV；XLSX公式须有缓存的数值结果。
- 六项顺序：平均深度μm、不均匀深度μm、对数径深比均值、对数坑深均值、两项对数标准差。读取非有限值、变量缺失、校准不成立会在提交前提示。
- 严格模式：NumPy、单worker、固定可编辑种子，每个完整个体和每代保存检查点；自动种子每次生成并保存在实际配置中。种子相同还需相同输入、参数、引擎和环境，不能保证不同后端之间逐位一致。
- 高速模式：需兼容当前Python的Taichi发行包，使用`requirements-fast.txt`安装。实际启用失败会报错，不伪称高速。高速模式不支持严格检查点恢复。
- 单阶段读取`SINGLE_STAGE_GA_CONFIG`，多阶段读取`STAGE_GA_CONFIG`；原循环最多运行`maxgen-1`代，保留原规则。
- 多工况支持single/sequential/parallel/mixed；混合模式先完成顺序组再启动并行组。全站最多同时运行2个任务，每个任务内部worker数仍需根据资源估算调整。
- 阶段完成后先保存数值，再生成图。图失败保留数值并报告警告；提供目标与实际指标、四项误差、10参数名称、收敛、分项耗时和阶段图。无法定义的分布指标显示缺失及原因。
- 原目标组合保留：删除第5项误差；深度均值/标准差误差按0.6/0.4合并；四项按0.1/0.3/0.2/0.4加权。阶段序号不表示腐蚀天数。

## 中断与恢复

任务进程关闭后，在运行记录中选择任务并点击恢复。保存的完整个体不用重算，未完成个体按原种子重算。检查点使用小元数据和不可变最优状态文件，保留上一有效快照。

恢复前检查配置、输入哈希、阶段文件、引擎与Python/NumPy/SciPy版本；不匹配时拒绝恢复，避免误用新规则续算旧任务。网页刷新或服务重启不会主动停止仍运行的任务，活动旧进程不会被重复启动。

程序中断恢复已用小任务验证；实际断电和磁盘故障不能据此视为验证通过。源代码更新后，正在运行的任务继续使用已加载代码；旧检查点可能因版本变化而不能在新引擎中恢复，应保留旧版本完成旧任务。

## 一键同步GitHub

双击`sync.cmd`，或点击网页“一键同步”，提交并推送**当前Git分支**上的网站源码。按钮旁“变更预览”展示分支、提交和待同步文件；同步拒绝夹带网站之外的已暂存文件；没有新改动也会尝试推送尚未上传的提交。

需要安装Git并登录对应GitHub账号；push失败时本机提交保留，处理网络/登录后再同步。不会强制推送或覆盖远端历史。

网站以独立`engine/`副本计算。原科研程序改动需要明确移植到网站副本并验证，不能自动覆盖网站的恢复实现或读取规则。

不提交`.runtime/`、上传数据、计算结果、日志、环境凭据、缓存及本机环境。GitHub中已有的示例目标文件沿用本仓库，不新增真实实验数据。
