# 腐蚀研究工作台

专业中文本机研究网站，连接“实测点云 → MATLAB六指标 → 单/多阶段CA–GA模拟”。网页实际启动本机计算程序，支持完整调参、文件检查、随机种子、进度、严格模式恢复、过程图与数值下载。

GitHub保存源码；计算服务运行在使用者自己的电脑上。直接浏览GitHub文件或静态页面不能启动本机MATLAB/Python。

腐蚀模拟网页默认使用 `pycharm` 模式：NumPy `ProcessPoolExecutor` 多进程，两个 GA 配置默认 10 个 worker，Taichi 关闭。完整阶段导出后可以复用；阶段内部中断时从当前阶段重新计算。需要逐个体精确恢复时，切换到 `strict` 模式。

第三部分新增**APDL单/双面腐蚀钢板单轴拉伸**：独立预检与运行区域，支持原GitHub双面49点MISO预设、可调尺寸、实体网格及模型ZIP导出；配置本机MAPDL后可调用求解并检查结果。完整来源、参数作用、操作及实际求解验收边界见[单双面APDL拉伸说明](docs/2026-10-15-APDL单双面拉伸使用与验收.md)。

## 一键打开

1. 安装Python，在本目录安装严格模式依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

2. 双击 **`打开网站.cmd`**。脚本寻找Python、检查依赖、后台启动并打开浏览器；默认固定使用 **8560**，同一源码版本已启动时复用服务，端口被其他服务占用时提示检查。
3. 手动启动可运行：

   ```powershell
   python start_server.py --port 8560
   ```

   打开 `http://127.0.0.1:8560/`。只允许本机访问。默认运行记录和日志存入 `D:\research\CorrosionWebsiteData`，可用 `--runtime` 指定目录；不要删除需要恢复的任务目录。

## 第一部分：实测点云六指标

- 上传参考扫描和其局部XYZ子集。支持TXT、CSV、TSV、XYZ，前三列为X/Y/Z有限数值，单位mm。预览实际点数、范围、采样图与读取时间。
- 不限制为60或190 mm；参考区列数、中央腐蚀区列数、裁边和网格间距可调整。文件必须满足原子集及齐平规则，不能把独立扫描默认为同一物理参考面。
- 从`matlab/step00_corrosion_config.m`生成完整参数目录；布尔值、数组、枚举均按真实类型提交。输入输出路径由独立任务管理，避免覆盖原实验数据。
- 六指标、原坑样本、MAT/CSV/Excel、图像和可用的APDL点云文本保存到本次任务outputs。物理校准状态不成立时可下载诊断，但不能把它作为有效模拟目标。
- 点云任务额外生成 `timing.json`，拆分输入读取、MATLAB 进程、脚本预处理/形貌分析/数值与图片导出、后处理与总耗时；预检报告重复点和零跨度坐标轴。MATLAB 脚本分项计时以 `matlab_timing.json` 为准。
- 点云任务完成后会自动把本组成果复制到 `D:\research\DATA\Point cloud extraction\<任务ID>`，并按 `01_参考点云`、`02_腐蚀细节点云`、`03_MATLAB六指标`、`04_过程图`、`05_诊断报告`、`06_原始任务包` 分类；任务目录中的 `outputs` 仍是计算源文件。每组目录包含 `归档清单.json`，记录来源、目标、文件数量和归档耗时。可通过环境变量 `CORROSION_POINTCLOUD_ARCHIVE` 修改归档根目录。
- 已处理平滑点云可按 X/Y 毫米尺寸和二维中心裁剪矩形区域，导出 MAT/CSV/XYZ 与区域元数据；可选记录试件长宽厚并报告扫描覆盖率。裁剪保留已有网格节点，不外推。当前深度仍是整幅最高点基准的相对起伏，不代表已验证的未腐蚀面绝对腐蚀深度，试件厚度不用于推算深度。
- 模拟结果记录运行环境、Git commit 和主进程观测峰值内存；多工况支持整批停止、失败工况检查点重试与 ZIP 打包下载。
- 提速边界与基准验收方法见 [`docs/2026-10-14-性能优化建议.md`](docs/2026-10-14-性能优化建议.md)，严格模式结果一致性要求保持不变。
- 安装MATLAB，并使`matlab`可从PATH调用，或设置：

  ```powershell
  $env:MATLAB_BIN = 'C:\Program Files\MATLAB\R2024b\bin\matlab.exe'
  ```

  原脚本使用`imgaussfilt`、`watershed`、`normfit`等函数，需要匹配的图像处理和统计工具箱。网站检查可执行文件，具体许可证与工具箱由MATLAB日志确认。

## 第二部分：单/多阶段模拟

- 完整目录来自`engine/01_运行程序与数据/unified_config.py`。每项附标签、作用和适用范围；材料拟合等后续字段可以保存，但当前CA/GA不会使用它们。
- 输入MAT、CSV、TXT、TSV、XLSX或手动N×6矩阵。MAT自动列出变量和行列，XLSX读取当前工作表并允许首行文字表头；可选择按行N×6或按列6×N，6×6需要明确方向。支持普通v7 MAT，v7.3需另存v7或六列CSV；XLSX公式须有缓存的数值结果。
- 六项顺序：平均深度μm、不均匀深度μm、对数径深比均值、对数坑深均值、两项对数标准差。读取非有限值、变量缺失、校准不成立会在提交前提示。
- 严格模式：NumPy、单worker、固定可编辑种子，每个完整个体和每代保存检查点；自动种子每次生成并保存在实际配置中。种子相同还需相同输入、参数、引擎和环境，不能保证不同后端之间逐位一致。
- 高速模式：需兼容当前Python的Taichi发行包，使用`requirements-fast.txt`安装。实际启用失败会报错，不伪称高速。高速模式不支持严格检查点恢复。
- 单阶段读取`SINGLE_STAGE_GA_CONFIG`，多阶段读取`STAGE_GA_CONFIG`；原循环最多运行`maxgen-1`代，保留原规则。
- 多工况支持single/sequential/parallel/mixed；混合模式先完成顺序组再启动并行组。全站最多同时运行2个任务，每个任务内部worker数仍需根据资源估算调整。
- 阶段完成后先保存数值，再生成图。图失败保留数值并报告警告；提供目标与实际指标、四项误差、10参数名称、收敛、分项耗时和阶段图。无法定义的分布指标显示缺失及原因。
- 原目标组合保留：删除第5项误差；深度均值/标准差误差按0.6/0.4合并；四项按0.1/0.3/0.2/0.4加权。阶段序号不表示腐蚀天数。

## 性能对比：Taichi与并行

左侧“性能对比”是第二部分的独立辅助运行区。先在“腐蚀演化”确认目标和科学参数，再选择快速预设或采用当前GA配置。测速覆盖参数保存在独立快照，不写回正式模拟配置。

- 比较 NumPy 单进程、多进程、Taichi CPU、Taichi GPU，并可追加 Taichi CPU/GPU 多进程组合。NumPy 单进程始终作为基准。
- 支持两种独立工作负载：固定种群一代CA适应度；短程原GA（保留选择、交叉、变异及提前停止，最多1–10代）。短程GA显式设置选择数量，必须小于种群数量；不包含正式任务的检查点、绘图及导出开销，不能直接预测完整项目耗时。
- 初始状态可选全新表面或已完成模拟的某个阶段。已有阶段冻结 `stage_XXX.npz`，下一阶段编号为来源阶段+1；维度及XY/Z物理间距必须匹配，不隐式重采样。点击“采用源网格与物理间距”只影响本次测速快照。
- 每个方案在独立进程运行，首次评估与预热后1–7次重复分开，报告中位数、最小/最大、Q1/Q3/IQR及原始样本。首次含惰性编译。“重建池”计入每次建立及初始化worker；“常驻池”首次建池，后续样本复用worker。CA、原形貌后处理及数组传输均计入评估；Python启动、设备初始化、读取、数值导出及对照分析另记。
- “功能自检”使用5×6×4、F=3、2个体、重复1次，适合确认流程；“性能基准”使用40×40×16、F=8、6个体、重复5次。支持最多3种子、4种进程数、两种池及固定/随机执行顺序；单进程不重复池方案。实际进程数不超过种群数量，记录请求值与实际值。
- 每进程线程数与逻辑CPU预算可编辑；进程数×线程数超过预算或本机逻辑CPU数会拒绝。累计全部方案的主机数组估算超过1 GiB或预计工作量超过20亿元胞步也会拒绝；不自动缩小科学参数。预算是估算，不是实际内存上界。
- 固定种群比较所有个体六项舍入误差 `objv`，短程GA比较最终四项误差和最优参数；均比较 `a/d/cl` 完整状态。报告最大绝对差、RMSE、变化数量/比例；数值容差 `rtol=1e-7, atol=1e-9`，分类状态 `a` 必须完全一致才算容差内。另列重复一致性、实际表面深度差图及六项形貌指标；无法定义的指标显示空值和原因。
- 实际CPU/GPU架构在父子进程核验；缺依赖、DLL加载失败或GPU回退均明确报告，不生成伪GPU加速比。单项失败、超时不会清除其他方案；基准失败时所有加速比留空。
- 测速独占本服务两个计算槽，其他本服务任务等待；其他应用仍可能影响结果。50ms采样父子进程RSS之和，可能重复计共享页、漏瞬时峰值，不含GPU显存。
- 服务重启后会接管仍运行任务的槽位；停止旧进程前核验PID、创建时间、锁文件、完整worker命令、工作目录及运行目录。旧版任务缺少身份记录时会拒绝接管停止。停止保留已完成方案，未完成测速不支持检查点恢复；“重新测量失败项”创建新任务，并重新测同种子基准，不合并旧样本。
- JSON/CSV逐方案保存，ZIP点击下载时生成并缓存，打包时间单独记录。来源快照包含在包内；默认保存首次和最终状态NPZ，可取消保存明细以减少最终磁盘占用。采用方案先显示配置差异预览，确认后才更新正式模拟配置；NumPy严格模式仍使用单worker，种子默认保留。

Taichi安装方式沿用 `requirements-fast.txt`。点击“本机环境诊断”分别检查软件包、原生扩展导入、CPU/GPU最小内核和实际架构，不能只用“已安装”判断可用。本机若已有兼容运行库但默认加载路径不可见，可在启动网站的同一PowerShell会话中显式指定：

```powershell
$env:CORROSION_NATIVE_DLL_DIR = 'C:\可信的64位运行库目录'
python start_server.py --port 8560
```

目录必须已存在且包含 `MSVCP140.dll`。只在当前Python进程及其子进程添加DLL目录和加载该文件，不修改系统PATH、注册表或安装运行库；诊断记录实际路径与SHA-256。显卡驱动及内核是否可用仍以实测为准。验收范围见 `docs/2026-10-15-性能对比第二轮验收记录.md`。

## 中断与恢复

任务进程关闭后，在运行记录中选择任务并点击恢复。保存的完整个体不用重算，未完成个体按原种子重算。检查点使用小元数据和不可变最优状态文件，保留上一有效快照。

恢复前检查配置、输入哈希、阶段文件、引擎与Python/NumPy/SciPy版本；不匹配时拒绝恢复，避免误用新规则续算旧任务。网页刷新或服务重启不会主动停止仍运行的任务，活动旧进程不会被重复启动。

程序中断恢复已用小任务验证；实际断电和磁盘故障不能据此视为验证通过。源代码更新后，正在运行的任务继续使用已加载代码；旧检查点可能因版本变化而不能在新引擎中恢复，应保留旧版本完成旧任务。

## 第三部分：APDL单轴拉伸与表面输入包

- 顶部工具栏“外部 NPZ → MAT”可直接进入外部导入；在转换卡片点击“导入外部 .npz”选择文件，不要求文件名为 `simulation.npz`，也无需先创建本机模拟任务。
- “有限元耦合”顶部“模拟结果 → MATLAB 表面”按原 MATLAB 流程导出 `baseline[X,Y]`：沿完整存储 Z 轴查找首个金属（从 1 编号；无金属取 n+1），`imgaussfilt` 等价高斯滤波（核半径 `ceil(2*sigma)`、复制边界），对称边界移动平均，再做最近邻整数倍放大。MAT 只含二维 `baseline` 数值矩阵，不附带元数据、坐标或图片，不换算物理单位。
- 可调参数为平滑窗口（1～101 奇数）、高斯 sigma（0～100，0 关闭高斯）、放大倍数 N（1～10，放大后最多 400 万元素）和物理 Z 层数 n（Z 或 Z−1）。w/l 从 NPZ 读取。默认窗口 5、sigma 1、N=1 来自 `untitled.m` / `moving_avg_3D.m` 示例，`CA.m` 还使用窗口 11；这些示例值不代表已经确认旧 `100d.mat` 的保存参数。n 优先读原任务 `grid_n`，外部 NPZ 默认 Z−1 并允许确认改为 Z。
- 网页支持已完成任务或外部 NPZ，并可选状态变量及阶段。输入检查后显示原矩阵与放大后的输出行列；无需配置 JSON 或 XY/Z 微米尺寸。生成任务冻结 NPZ 与所选参数。历史未平滑的矩阵任务及带尺寸元数据的 MAT 保持原有读取规则。
- 生成后下载 `baseline.mat`。该文件的数值为层号，有限元建模中的单位、间距及高度换算另在二维矩阵导入流程设置。历史已生成的带尺寸元数据 MAT 仍按原规则读取，历史任务不改写。
- 在“有限元耦合”运行区选择已完成的 CA–GA 模拟任务或实测表面 MAT 任务。
- simulation 来源读取最终 `perfect_a`（或兼容的 `a_sd` 最后一阶段），沿 Z 方向寻找第一层未腐蚀金属并转换为正腐蚀深度；measured 来源保留 `Z_filled/F_filled` 的二维尺寸和数值，不默认重采样。
- 有外部 CA 状态时，可在每个正/反面来源选择“上传外部 NPZ”。文件必须包含数值实数 `perfect_a[X,Y,Z]`，或数值 `a_sd[X,Y,Z]` / `a_sd[stage,X,Y,Z]`；网页会列出变量、原始形状、可选阶段和读取耗时。四维阶段按文件存储顺序从 1 编号，默认最后阶段，序号不等于腐蚀天数。
- NPZ 可包含 `space_xy_um` 与 `space_z_um` 单值正数元胞尺寸；文件提供的尺寸会锁定，缺失尺寸必须按原模拟配置补填，不能覆盖文件已有尺寸，也不会猜测 60 mm/190 mm 等板面尺寸。状态轴固定解释为 `[X,Y,Z]`，状态值 1 表示金属，沿 Z 使用原有“第一层金属”规则。
- 旧模拟若只有 `dtype=object` 的历史 `a_sd`，网页不会执行 pickle；请在可信环境将所需阶段另存为数值三维数组。包含数值 `perfect_a` 的同包文件仍可直接读取最终状态。普通 ZIP、二维深度矩阵或仅参数的 NPZ 不能作为三维腐蚀状态。
- 可调输出变量、Z 向元胞尺寸、XY 网格间距、坐标原点和坐标精度。单位在表单中明确显示：输入 Z 向元胞为 μm，APDL 表面深度和坐标为 mm。
- APDL 也支持直接上传 MATLAB 坐标导出的 `DIANYUN_FRONT_X/Y/Z.txt` 或 `DIANYUN_BACK_X/Y/Z.txt`（也支持 CSV/TSV）。单面只需一组 X/Y/Z，双面需要两组；网页自动读取真实 `dx/dy`、恢复完整 XY 网格并拒绝重复点、缺点、不规则间距和双面错位，不进行插值。正面深度按 `max(Z)-Z`，反面按 `Z-min(Z)`，可在每面选择方向规则。
- 每次导出生成 `Z_filled.mat` 或 `F_filled.mat`、`surface.csv`、`coordinates.csv`、可用的 `surface_preview.png`、`finite_element_manifest.json` 和 `finite_element_input_bundle.zip`。manifest 保存源任务、输入哈希、尺寸、范围、规则和每个文件的 SHA-256。
- 保留原表面导出入口；完整拉伸在独立 APDL 运行区选择无腐蚀、单面、独立双面或对称双面，配置材料、厚度分层、约束与加载。可仅生成模型，配置本机 MAPDL 后可批量求解；GitHub 脚本不能代替本机 ANSYS 与许可证。
- 来源切换清除旧阶段/文件；输入即时保存，刷新不丢草稿。双面配准确认绑定来源文件 SHA、来源身份及坐标映射，变更后需重新确认与预检；服务器拒绝过期签名。
- 结果检查逐步加载、两端反力、应变/应力定义，并将节点号、初始坐标及端部 UX 与实际网格及曲线交叉核验。节点 `E13.5` 采用无 `1P` 的 Fortran 五有效位精度容差。当前尚未解析二进制 RST，统一标为“尚未核验 / 需要复核”，不能视为完整数值验收通过。
- Windows 新建 APDL 求解使用受控启动器与 kill-on-close Job Object；实际程序只在监管分组及执行记录保存成功后启动。停止核验 worker 身份、清理并确认求解组为空；失败明确保留“停止失败 · 可重试”，不会宣称已停止。真实 ANSYS/MPI 与许可证兼容性仍待实算验证；旧任务不会自动改用新监管机制。
- 读取、几何、写包、求解、后处理的成功与失败用时分别保存，失败保留输入与执行日志；停止保留部分文件并明确结果未完整验收。MAPDL 重启动文件可下载，尚不提供网页一键续算。

详细规则见 [APDL单双面拉伸使用与验收](docs/2026-10-15-APDL单双面拉伸使用与验收.md)，本轮修复与验证见 [APDL前两轮整改验收](docs/2026-10-15-APDL前两轮整改验收.md)。

### APDL诊断与结果保存

- **材料覆盖提示**：按实际模型长度估算目标工程应变、均匀真应变和 MISO 末点覆盖；49点原始材料曲线不作修改。真实求解后另保存逐子步元素节点等效塑性应变最大值及位置，仅作筛查，不能代替积分点核验。
- **命令流内部自检**：导入后检查节点/单元数量和编号范围，原边界创建后检查两端节点数、所在端面及是否重叠；失败输出 `APDL_SELF_CHECK_FAILED` 并退出，不进入求解。
- **网格质量报告**：Python 分块计算角点 scaled Jacobian、边长比和最差单元位置；MAPDL 实际运行时输出原生 `SHPP,STATUS/SUMMARY` 报告。预检不自动修补网格，不修改 SOLID185 积分或质量阈值。
- **结果保存模式**：默认完整保存，另可只保存末步单元场或按加载比例保存。位移/反力曲线仍保存全部收敛子步，MISO 的材料筛查历史也逐子步保留。比例是 `TIME=1` 的加载份额，不是秒；不改变加载和求解子步。末步节点 CSV 与重启动保存另行控制。

这些检查不等于真实求解验收。当前环境未发现 MAPDL，实际 ANSYS 命令执行、RST 内容、网格收敛及材料积分点覆盖仍需本机求解后验证。详细设计见 [APDL四项增强设计](docs/superpowers/specs/2026-10-15-apdl-diagnostics-output-design.md)。

## APDL 结果说明

任务详情和运行记录根据保存的日志、六列曲线及非空 RST，分别说明目标加载完成情况与待复核事项。每类异常显示原因、影响、处理建议和原始日志行号；材料筛查显示曲线末点、最大单元节点等效塑性应变与首次超表位置，不冒充积分点验收。
