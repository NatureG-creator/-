# APDL 交互查看入口

有限元耦合页面和已结束有限元任务的结果页新增“在 APDL 中交互查看构件”。先选择任务，再选择初始图像，点击“在 APDL 中查看”。功能调用本机 Mechanical APDL 图形界面。

## 可查看内容

| 网页选项 | APDL 顶部按钮 | 内容 |
| --- | --- | --- |
| 构件外形 | MODEL | 未变形外表面 |
| 有限元网格 | MESH | 未变形单元网格 |
| 变形对照 | DEFORM | 真实比例变形与未变形轮廓 |
| 总位移 | DISP | U,SUM，mm |
| 等效应力 | STRESS | S,EQV，MPa，节点平均 |
| 等效塑性应变 | PLASTIC | EPPL,EQV，无量纲，节点平均 |

必须保留 corrosion.db。只有保留非空 corrosion.rst 的任务才提供结果云图；弹性或材料类型未确认的自定义命令任务不提供塑性应变快捷按钮。未完整完成的任务会提示结果可能仅为部分载荷。自定义命令任务的单位需要自行核对。

## 实现与源文件保护

- 接口：GET /api/apdl/viewer/jobs；POST /api/apdl/jobs/{id}/viewer，正文仅使用白名单 view。
- 每次创建 runtime/apdl_viewers/{会话ID}，记录 session.json、启动日志和独立宏。所有读取路径从已验证任务 ID 生成。
- 启动使用本机 ANSYS 版本启动器的 -g -d win32 -np 1 -j viewer -s read。交互模式不能带批处理的 -i/-o。
- start.ans 读取 viewer.inp；清空命令使用 /CLEAR,NOSTART，避免重新读取 start.ans 形成递归。
- RESUME 源数据库后先 FINISH，再设置本地作业名。结果视图在 /POST1 中显式读取源 RST 的最后保存结果集。
- 使用原生 /MREP 重绘宏，避免 GUI 初始化及后续旋转、缩放将云图替换为默认节点图。各按钮载入相应独立宏。
- /EDGE 对单元图与云图的 KEY 含义不同：MESH 使用 0 显示相邻单元面边界，MODEL 使用 1 保留几何特征边。
- 查看宏不含 SOLVE、SAVE、UPGEOM，不改材料或加载。关闭 GUI 时可选 Quit - No Save。GUI 生命周期独立于网站任务进程。
- HTTP 成功仅表示已请求启动，不能据此认定窗口已经载入或许可证已可用；启动问题检查会话日志。

## 2026-10-17 真实验证

环境：Windows、本机 MAPDL 2025 R2。

1. 小型弹性任务 bb2e6ea5c9904ed4 自动打开节点平均应力图，显示 20.6 MPa；确认出现 MODEL/MESH/DEFORM/DISP/STRESS 按钮，未出现 PLASTIC。实测可切换视图。
2. 从最终网页入口打开 b6da8d7c0eb64167（z190_49点MISO_0.5mm_大变形），会话 a328afa6936145d6。打开后直接显示应力云图，TIME=1、STEP=1、SUB=12，最大等效应力 394.323 MPa、DMX=0.500257 mm。点击 PLASTIC 后实际切换至 EPPLEQV(AVG) 云图，最大等效塑性应变为 .859E-03，变形量仍为 .500257 mm。
3. 原 corrosion.db、corrosion.rst、materials.mac、solve.mac 的 SHA256 在查看前后完全一致。未重新求解，49 点材料曲线不变。
4. 后端 APDL 专项 164 项通过（含查看器 6 项）；前端 APDL 专项 43 项通过；JavaScript 语法检查和 git diff --check 通过。

原任务的独立数值交叉验收仍为 needs_review。本功能的真实图形验证不改变该研究验收状态。
