# 运行记录管理与续算

范围：仅新增记录隐藏、恢复显示、确认删除和续算说明，不改模拟算法、输入、种子或材料参数。

1. 先测后端和 HTTP：隐藏不改变成果/检查点；删除需要匹配任务编号；运行/导出/被引用的任务禁止删除；外部导出目录保留。
2. 加入运行记录操作和隐藏记录筛选：默认隐藏已隐藏记录，其他模块的数据来源仍可读取它们；前端取消删除不发送请求。
3. 临时任务验证接口与界面；不删除实际成果，不启动模拟，不中断现有服务。

续算入口：运行记录 → 原任务 → 恢复，或查看原任务后的恢复按钮。检查点存在仅是初步条件，后端恢复时还校验输入、配置和程序指纹。

- strict：完整检查点支持阶段、代/个体及随机状态恢复；尚未保存的工作重新计算。
- pycharm：仅复用已完整导出的阶段；中断阶段重新计算。单阶段未完成且无阶段成果时必须按原配置重新运行。
- fast/Taichi：目前不支持网页续算。
- 载入本次配置会创建新任务，不是原任务续算。续算不能改变参数或种子。
- 隐藏保留检查点；永久删除同时删除任务内成果和检查点，不能继续该任务。外部已导出的副本保留。

各服务实例的新版创建任务、恢复和记录管理使用同一运行目录锁；旧版服务不具备此协议，升级时应统一入口。记录管理不对历史版本服务发出停止或重启命令。
