# MATLAB 二维矩阵自动坐标转换

APDL 表面输入现在支持在网页中直接把二维矩阵交给 MATLAB，自动生成并登记三份规则网格坐标文件：`DIANYUN_X.txt`、`DIANYUN_Y.txt`、`DIANYUN_Z.txt`。

## 使用步骤

1. 在 APDL 单轴拉伸区域选择“单面腐蚀”或“双面独立”。
2. 将读取方式设为“上传二维矩阵”，上传无表头的 `MAT`、`CSV`、`TXT` 或 `TSV`。
3. 填写 X/Y 物理间距；需要时填写 X/Y 原点。MAT 文件含有 `Z_filled` 与 `F_filled` 时，先选择变量。
4. 点击“用 MATLAB 转换为 APDL X/Y/Z”。网页调用本机 `matlab -batch`，完成后自动切换到坐标来源并显示三份文件。
5. 点击“预检并预览”，继续现有的单面、双面配准、建模和 MAPDL 求解流程。

转换保持原有 MATLAB 规则：`meshgrid` 生成坐标、`(:)` 按列优先展开；不插值、不重采样。生成文件随后经过已有的规则 XY 网格、长度一致、重复点和有限值检查。

## 依赖与故障提示

网页使用 `/api/apdl/matlab-convert` 调用 `MATLAB_BIN` 或系统 PATH 中的 `matlab.exe`。如果 MATLAB 启动失败，网页会显示 MATLAB 的原始错误，二维矩阵不会被静默改用其他算法转换。
