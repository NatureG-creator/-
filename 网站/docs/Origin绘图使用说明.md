# 本机 Origin 绘图

## 网页入口

打开工作台，在“通用数据拟合”或“双自变量拟合”中完成拟合；也可以在“运行记录”中打开已完成的拟合任务。结果说明下方提供“调用 Origin 绘图”卡片。选择数据组和成功候选模型，展开细部设置，然后点击“调用 Origin 绘图”。任务完成后显示图片、运行用时和文件下载。

本功能调用本机 Windows Origin，需安装并激活 Origin；网站使用的 Python 环境需安装 `requirements.txt` 和可选的 `requirements-origin.txt`。软件安装检测与实际许可运行分开记录，执行失败时请查看任务的 `origin.log`。

## 可调内容

- 图标题、坐标轴名称与单位、字体、标题及轴刻度和图例字号。
- 二维曲线线型、线宽；观测点形状、颜色、大小、透明度和显示开关。
- 坐标范围、X/Y线性或对数坐标、轴反向、主次刻度和网格。
- 图例位置与边框、页面宽高（mm）、PNG/TIFF分辨率（DPI）。
- 三维曲面的方位角、仰角、配色、色标范围与标题、Z轴范围。

本机实测中，三维色标数字的字体仍沿用 Origin 模板，轴标题和色标标题使用指定字体。该限制会在绘图结果中显示；色标数字字体可通过“在 Origin 中继续编辑”调整。

每次修改设置后创建一个新的绘图任务。单变量图使用已保存的观测点和拟合曲线；双变量支持二元线性、交互项、二次响应面，用固定拟合系数生成30×30网格。此过程不会重新拟合或修改来源任务。暂不支持自定义双变量函数直接生成 Origin 曲面；原有 Python 图与 Origin 交换文件仍可使用。

## 输出与继续编辑

任务保留 PNG 预览、所选 PNG/TIFF/PDF/SVG、`origin_project.opju`、观测与预测 CSV、参数配置、来源哈希及运行日志。PDF/SVG 中的三维 OpenGL 图可能含栅格内容，不承诺全部对象为矢量。

点击“在 Origin 中继续编辑”会在独立 Origin 实例中打开工程副本。可在 Origin 中进一步编辑轴、符号、标注、排版并保存。手动修改不会反向写回网页设置，也不会覆盖该任务的原始输出；编辑副本保存在任务目录的 `editing` 子目录。

自动绘图任务使用独立串行通道，不占腐蚀模拟任务槽；实际并行运行仍会共享电脑资源。停止自动绘图只处理已确认属于本任务的 Origin 进程。程序崩溃、许可或导出异常会记录真实失败状态，已产生文件保留供排查。
