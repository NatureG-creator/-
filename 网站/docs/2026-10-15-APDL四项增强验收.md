## 范围与保持不变的内容

本次增加材料覆盖提示、命令流内部自检、网格质量报告和结果保存模式。沿用 GitHub 原始49点 MISO 曲线，包含下降段，不补点、不平滑、不延伸材料曲线。原 CA/GA/MATLAB 源码、双面装配、网格连接、边界约束、加载、子步和大变形设置保持原有逻辑。

## 网页使用

1. 打开“有限元耦合”，按原流程选择无腐蚀、单面或双面形貌并确认物理尺寸。
2. 在“结果文件保存”选择模式。默认完整保存；“仅末步单元场”控制末步单元场保存，位移与反力曲线仍逐收敛子步保存。MISO 的材料筛查历史也逐子步保留；“指定加载比例”当前因 MAPDL 输出兼容限制实际回退为完整保存，比例只作为请求记录。
3. 指定比例须用英文逗号分隔，严格递增、在 `(0,1]` 内、1至20项并包含1。比例是静力加载步 `TIME=1` 的加载份额，不是秒。当前 MAPDL 实际完整保存这些结果，不改变求解步长，也不减少 RST 体积。
4. 点击“预检并预览”，查看材料覆盖估算、网格指标和最差单元位置。参数修改使预检失效，提交时自动重检。
5. “仅生成模型”可下载输入包。“生成并求解”要求本机 MAPDL 和可用许可证；真实运行后才会生成内部自检、ANSYS 原生质量与材料筛查文件。

末步完整节点 CSV 与 RST 历史保存是独立选项；重启动文件仍由原保存频率控制。减少 RST 场输出不代表已证明加速，需实测磁盘量与总耗时。

## 材料覆盖提示的含义

按实际长度计算 `delta/L` 和 `log1p(delta/L)`，对比原曲线末点的总应变估算 `末塑性应变 + 末应力/E`。超过时提示风险，不阻止运行、不更改曲线。均匀估算未超过也不能保证腐蚀热点仍在范围内。

例如原模型跨度57.6mm、加载11mm时，工程应变约0.190972，均匀真应变约0.174770；原曲线末塑性应变0.137798、末应力621.16MPa、E=185226MPa，对应总应变估算约0.141152和均匀延伸约8.73mm。因此该配置需要重点复核材料覆盖。

求解后的 `NL,EPEQ` 最大值取自 `ETABLE,...,MAX` 的**元素节点值筛查**，记录单元与重心位置，不冒称积分点最大值。筛查未见超表不能证明所有积分点被材料表覆盖。原节点 CSV 的 `EPPL,EQV` 含义保持不变。

筛查按无 `1P` 的 `E19.11`（11有效位）导出精度，采用末点值的 `5.1e-11` 纯相对容差判断明确超出；不使用固定绝对容差掩盖很小末点的实际超界。末点附近的结果集另计数并显示“精度边界待复核”，不据此宣称材料覆盖通过。

## 自检与质量报告

- 导入网格后核对实际节点、单元数及编号范围；原边界创建后核对两端节点数、端面位置及互不重叠。
- 自检失败输出 `APDL_SELF_CHECK_FAILED` 并退出，外部程序识别该标记；不能把零退出码直接当作已完成求解。
- `apdl_self_check.csv` 是实际 MAPDL 执行产生的两阶段记录，不在生成输入包时预造。
- Python 的角点 scaled Jacobian、边长比和最差单元重心仅是几何预警。小于0.1是提示阈值，不是 ANSYS 验收标准，不自动修网格或放宽质量限制。
- 实际 MAPDL 运行生成 `mesh_quality_report.txt`，保留 `SHPP,STATUS` 和 `SHPP,SUMMARY` 原文；文本存在本身不等于质量通过。
- 新诊断字段使用独立版本，旧任务仍按原结果合同读取。新任务缺少或损坏必要诊断文件不得补零或伪报通过。
