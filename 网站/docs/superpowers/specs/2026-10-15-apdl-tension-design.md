# 单双面腐蚀钢板APDL单轴拉伸设计

用户已选择单轴拉伸作为第一项力学验证。沿用此前单/双面方案，第一版聚焦三维实体建模、受控拉伸输入包、本机MAPDL执行与结果核验；原表面导出兼容保留。

## 数据与几何

- 新任务类型 `apdl_tension`，运行模式 `build` / `solve`。来源可为已完成模拟的阶段NPZ、已完成实测任务中的MAT，或已上传的MAT/CSV/TXT/TSV矩阵；不接收任意文件系统路径。
- 腐蚀模式 `flat` / `single_top` / `single_bottom` / `double_independent` / `double_symmetric`。
- 每面来源显式记录类型、变量、行列约定、单位、正深度或相对基准高度、参考值、转置与X/Y翻转。模拟读取第一金属层规则，原row=X/column=Y明确转成统一矩阵 `depth[row_y,column_x]`；实测必须核对约定。
- 全部深度内部转成正值mm。原板底z=0、顶z=t0：`z_top=t0-top_depth`、`z_bottom=bottom_depth`、`remaining=t0-top_depth-bottom_depth`。不裁切负厚度、不自动修补穿透、不隐式重采样。
- 两面独立来源必须维度、dx/dy及原点相同，用户确认同一物理位置配准。对称模式明确复用同一已注册深度场；不冒充独立随机样本。
- 本版以采样点作有限元节点，长度 `(nx-1)*dx`、宽度 `(ny-1)*dy`，明确区别元胞中心采样跨度与原CA域宽度。无腐蚀基准允许直接设置L/W/nx/ny。
- 仅厚度方向分层可调；完整保留XY采样，不自动降采样。预检节点/单元数量、剩余厚度、体积损失、形貌范围、网格层数；超过约定节点/单元预算拒绝，提示明确预处理。

## 有限元与加载

- GitHub原始双面源 `model3_recommended.inp` blob `eb0457cfde976f2bae16b255ebbf0bae78486dd4` 提供独立预设：E185226、ν0.3、49点MISO、允许原曲线负斜率、8层、11mm位移、100/450/50子步、大变形和原角点约束。默认弹性验证工况不被覆盖。
- 原MATLAB预处理 blob `97965bfaa3db04633d2d57a1a5c6a67b8588e3dc` 对双面分别显式中心裁193列，之后取max(height)-height；原反面负号是高度方向变换，不是XY镜像。新装配仅差整体Z平移，等价性用非对称矩阵测试。
- 原单面APDL说明确认没有独立单面求解宏；网页用同一实体网格将另一面设为平面，参数与原双面可对照。原Area=120未用于原力位移输出；网页名义应力统一除以实际width×thickness。

- 使用八节点SOLID185、规则XY网格、各列在上下表面间线性分层。节点与单元连接顺序明确，校验正厚度、正体积与长宽比；不声称主机几何检查等同ANSYS网格质量验收。
- 载荷沿全局X，x=0端UX=0，x=L端UX=目标拉伸位移。默认自由泊松收缩：固定端一个角点UY/UZ为0，另一横向角点用约束方程去掉绕X刚体转动，保持泊松收缩可行。另提供两端夹持约束模板，说明端部横向收缩受限。
- 默认材料线弹性，E、泊松比可编辑；可选双线性等向硬化，屈服与切线模量显式输入。N-mm-MPa单位制；默认材料只是示例，需替换为试验值。
- 可调目标位移、子步、大变形、CPU核数、求解超时、末步完整场导出。首版不包括断裂、接触、壳模型、压缩屈曲和弯曲。
- 默认基准L100mm/W20mm/t6mm，E206000MPa、ν0.3、目标位移0.1mm；理论刚度EA/L、理论反力EAδ/L仅标为解析参考，未调用MAPDL时不生成伪数值结果。

## 任务与输出

- `/api/apdl/capabilities` 检查可执行文件；`/api/apdl/presets` 给出原脚本预设与来源；`/api/apdl/precheck` 解析与校核；`/api/apdl/jobs` 创建独立任务；查看/停止/下载复用既有任务接口。
- 计算源文件逐面冻结并验证SHA；配置、变换与源几何写入manifest。支持独立工作目录、超时、进程树清理和日志；不修改全局PATH/原科研目录。
- `build` 生成纯ASCII APDL主宏、节点/单元、材料、边界、求解、后处理宏，以及深度/剩余厚度CSV、输入NPZ、预览、manifest、ZIP和中文运行说明。
- `solve` 在上述输入包基础上调用明确配置的MAPDL可执行文件。只有进程退出、日志检查、输出文件和收敛结果共同满足条件，才标为求解完成；缺求解器/许可证/结果或不收敛均明确失败，保留已有输入和日志。
- 输出载荷—位移与工程应力应变CSV（工程应力以原始截面面积计算）、两端反力平衡、最后收敛载荷、完整场选项开启时的末步节点位移/平均等效应力及塑性应变。峰值仅是已保存曲线峰值，不宣称线弹性求解给出极限承载力。
- 非线性输入配置MAPDL自身重启动文件保存，网页展示保留文件；首版不承诺未经实际MAPDL验证的一键续算或任意断电恢复。
- 单项预览/绘图失败保留数值和APDL文件并记录警告；分开记录读取/几何/写入/求解/后处理/总耗时。

## 验证与验收

- 单/双面固定深度、非方形方向、单位与变换、剩余厚度拒绝、双面不匹配、节点连接和正体积测试。
- 无腐蚀基准解析EA/L检查与生成宏约束检查；真实求解器可用后运行基准并核对数值反力、刚度与平衡。未定位求解器时明确记录未通过实际ANSYS验收。
- 任务来源约束、源冻结、错误/超时、真实子进程管理与严格结果解析测试；前端类型、模式切换、双来源、预检和下载浏览器验收。
- 回归现有点云、CA/GA恢复、性能基准和原有限元表面导出；运行输入/结果/缓存不提交GitHub。
