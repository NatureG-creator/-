# PATH_CONFIG 数据工作区设计

## 目标

将统一配置中的 10 个 `PATH_CONFIG` 路径默认放到 `D:\research\DATA\Corrosion modelling`，目录和文件使用中文名称并以工作区编号结尾；网站可以切换根目录和编号，也可以逐项编辑完整路径。

## 方案

- 默认编号为 `1`。
- 目录名称为“任务输入目录”“任务结果目录”“自动图片目录”“形貌参数结果目录”“曲线结果目录”“曲线输入目录”，文件名称为“断裂试验输入文件”“材料试验输入文件”“长期腐蚀输入文件”“曲线元信息文件”，文件统一使用 `.csv`。
- 网站新增工作区快捷区：根目录、编号、生成路径、应用路径；应用时由后端创建目录和文件父目录，不覆盖已有文件。
- `PATH_CONFIG` 仍保留 `inputs`、`outputs`、`auto_plots` 等内部键名，现有 CA、GA、MATLAB、拟合入口无需改调用方式。
- 路径字段从只读改为可编辑；每次任务提交仍冻结实际完整路径，便于复现。

## 校验与错误处理

- 所有路径必须是非空字符串，拒绝 NUL 字符。
- 应用路径只创建目录，不创建或覆盖 CSV 文件。
- 配置校验继续检查字段集合和 JSON 可序列化性；应用失败时返回明确错误，不影响当前网页状态。

## 验证

- Python 单元测试检查默认路径、路径可编辑属性、路径校验和目录应用接口。
- 前端状态测试检查编号切换生成 10 个对应路径。
- 运行网站默认接口并调用应用接口，确认返回完整路径和已创建目录清单。
