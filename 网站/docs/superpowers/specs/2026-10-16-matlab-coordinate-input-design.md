# MATLAB 坐标文件输入设计

## 目标

在 APDL 单轴拉伸耦合区增加 MATLAB 坐标文件输入方式，直接接收现有 `dlmwrite` 生成的正面/反面 X、Y、Z 文本文件。单面只需一组坐标，双面需要两组坐标；坐标经过完整性、规则网格、方向和厚度校验后，转换为现有 APDL 深度矩阵，不改变 CA 状态提取、单双面装配或 49 点材料曲线。

## 输入契约

- 每个表面由 X、Y、Z 三个数值文件组成，支持 `.txt`、`.csv`、`.tsv`。
- 文件可为一列向量，也允许只有一个数值列的分隔文本；不接受表头、非有限值、空文件或多列混合数据。
- 三个文件长度必须一致；展平后的 `(X,Y)` 点必须唯一且组成完整规则网格。
- 后端根据唯一坐标恢复 `ny × nx` 深度矩阵，并记录实际 `dx`、`dy`、坐标范围和展平顺序。
- 正面深度默认为 `max(Z)-Z`，反面深度默认为 `Z-min(Z)`；界面允许选择反向方向以适配外部坐标系。
- 单面没有另一组文件时，未腐蚀面按平面处理；双面必须两组网格形状和 XY 坐标一致。
- 原始坐标文件冻结到任务 `inputs/`，manifest 保存文件 SHA-256 和解析元数据。

## 数据流

网页为每个表面提供三个文件选择器和方向选择器。上传后后端创建组合上传记录并执行坐标检查；预检阶段调用坐标解析器生成深度矩阵，再复用现有几何、材料、网格质量和 APDL 命令流。创建任务时冻结三份/六份来源文件和坐标元数据，worker 只读冻结副本。

## 失败边界

- 文件数量不完整、长度不一致、坐标含 NaN/Inf、重复 XY 点、网格缺点或坐标间距不规则时拒绝预检。
- 双面坐标不一致、表面深度为负、剩余厚度小于等于 0 时拒绝预检。
- 网格质量严重低于现有阈值时保留“仅生成模型”能力，但阻止直接 MAPDL 求解，并说明最差单元位置。
- 不调用 MATLAB 脚本，不依赖 MATLAB 当前工作目录；MATLAB 仍可在前置步骤生成坐标文件。

## 兼容性

现有已完成任务、二维 MAT/CSV/TXT/TSV 和外部 NPZ 入口保持不变。坐标文件输入只增加一种来源类型，不改变原始 CA 到深度的规则。
