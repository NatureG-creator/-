# APDL命令编辑与材料、诊断、试验对照

用户已确认第一轮四项功能：命令流编辑、材料导入预览、求解诊断、试验曲线对照。保持现有参数建模路径、49点默认材料和已有任务不变。

## 命令流

从一个已结束且已生成输入包的APDL任务读取main.inp、materials.mac、boundary.mac、solve.mac、post.mac。页面提供文件切换、文本编辑、单文件导入导出、JSON模板导入导出、恢复源版本、差异和结构检查。节点/单元及现有自检宏在本轮保持源任务版本。

保存时另建apdl_tension任务，使用custom_commands执行模式；冻结源输入包、编辑文本和SHA256，保存源任务ID与差异。build模式只生成新包，solve模式显式调用现有MAPDL监管器。源任务、状态和已有结果不被覆盖。

命令检查限文件集合、文本、结构和包内引用，不冒充MAPDL完整语法或物理验收。自定义任务的原参数仅作来源记录，自动参数模式的目标位移、弹性参考等检查不套用到修改后的命令。自定义运行显示独立的未自动物理校核状态。

## 材料

复用现有表格读取器接受CSV/TXT/TSV/XLSX/MAT，显式选列、单位和应变类型。支持真塑性应变/真应力，或均匀拉伸阶段的工程、真总应变转换；后两者须明确确认数据来自颈缩前。百分应变和Pa/MPa可显式转换。拒绝缺失、乱序、负塑性应变，不自动排序、补屈服点或降采样。导入结果通过现有2至100点材料校验后写入现有参数框，源信息保留在材料导出JSON与新任务元数据中。

## 诊断

只读解析已有mapdl.out、corrosion.err、执行记录及网格报告，返回带文件名与行号的错误、警告、明确收敛记录和分类建议。只报告识别到的证据，不把未识别信息推断成收敛。正常与失败任务都可查看；不自动放宽容差或修改命令。

## 试验对照

对已有已结束的APDL求解任务，上传试验位移—力表，显式选择两列、mm或m、N或kN。首版仅比较单调加载分支，拒绝重复或非递增位移，不自动偏移、归零或选择卸载段。模拟与试验仅在共同位移范围内线性插值，输出RMSE、MAE、覆盖范围、有效行和叠加图；不外推、不自动标定材料，不将曲线峰值称为断裂强度。

每次对照保存为独立分析子目录并冻结试验原文件、映射和源曲线哈希，不改原科学输入或summary。支持自定义分析名称与另选导出目录。自定义命令任务必须明确确认CSV仍为原六列、位移mm和总反力N。

## 验收

- 原任务文件哈希在编辑/保存/对照前后不变；新任务输入被冻结且可追溯。
- 编辑引用缺失宏、越界文件、乱序材料和错误单位均被拒绝；自定义模式不误报原参数校核通过。
- 表格转换和插值误差用已知数值测试；不同单位输出一致；范围外不外推。
- 诊断提供真实行号、保留主要错误，读取诊断不改变求解状态。
- 组件、接口、前端测试与浏览器流程通过；真实MAPDL求解只在独立微型验证任务执行，结论明确区分输入包、进程执行和数值结果。
