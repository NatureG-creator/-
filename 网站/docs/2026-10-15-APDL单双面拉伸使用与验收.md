# APDL单双面腐蚀钢板拉伸：来源、使用与验收

## 本次接入范围

第三大部分新增独立的单轴拉伸运行区，可选择无腐蚀、正面腐蚀、反面腐蚀、双面独立形貌、双面对称形貌。原点云处理、CA–GA及MATLAB科学计算源不作修改；原表面文件导出保留为兼容入口。

工作流是：选输入 → 确认单位、方向和参考面 → 预检剩余厚度 → 生成SOLID185实体 → 拉伸求解 → 读取结果。仅生成输入包时没有有限元应力、反力或塑性应变结果。

- 原双面预处理：同运行包下 `01_MATLAB预处理/matlab_apdl_shuangmian_recommended.m`。Blob SHA：`97965bfaa3db04633d2d57a1a5c6a67b8588e3dc`。
- 原单面说明：`APDL_单面运行包/03_APDL建模求解/README_单面APDL说明.md`。Blob SHA：`64283c619b6e792feca90f365c24075d2ef15c64`。文件明确说明原项目未提供独立的单面求解命令流。

网页提供“GitHub原双面脚本 · 49点MISO”预设。保留E=185226 MPa、ν=0.3、49点塑性曲线、曲线下降段及`TBEO,NEGSLOPE,1`、8个厚度层、11 mm位移、大变形、100/450/50子步和原角点约束。原始曲线可查看和编辑，不会自动平滑。另有小变形线弹性平板预设，便于首先核对单位和反力。

原脚本的193列、60行、0.3 mm间距对应长度57.6 mm、宽度17.7 mm。网页按实际矩阵行列计算；行数无需固定60，列数无需固定193。仅选择原预处理预设时显式中心裁剪193列，列数不足报错，裁剪范围记录在来源信息中。普通导入不自动裁剪。

原代码中的反面`-F`是高度方向变换，并没有`flipud`或`fliplr`。预处理及装配可写成：

```text
d_top = max(Z) - Z
d_bottom = max(F) - F
z_top = t0 - d_top
z_bottom = d_bottom
remaining = t0 - d_top - d_bottom
```

这里的最大值在明确裁剪之后计算。新模型和原双面模型只差整体Z坐标平移，局部厚度不变。原宏声明`Area=120`，但其后处理仅输出力—位移，未用该面积计算应力。网页名义应力使用真实宽度×原厚度；60×193的6 mm板分母为106.2 mm²，不能悄悄套用120。

## 输入文件与坐标

1. 已完成CA–GA任务：选择最终`simulation.npz`或某个`stage_XXX.npz`，仍用第一层金属规则提取深度，继承真实XY/Z元胞尺寸。原行=X、列=Y明确转到统一行=Y、列=X。
2. 已完成点云任务：选择`Z_filled`或`F_filled`所在MAT。含两个变量时必须明确选取。继承可用的网格间距。
3. 上传二维MAT/CSV/TXT/TSV表面矩阵：CSV/TXT/TSV无表头，MAT使用上述两个变量。需要填写物理间距、单位和数值含义。三列XYZ点列表应先在第一部分变成规则表面；不要当二维深度矩阵直接导入。
4. 旧表面导出任务：自动继承row=X/column=Y、间距和原点；避免非方形矩阵方向错置。

内部统一为`depth[row_y,column_x]`，深度为向内的非负mm。高度数据必须指定参考高度或取最大值，以及高度方向。转置、X/Y镜像均为明确操作。模拟来源不能手改间距来重新解释物理尺寸。

双面独立形貌必须同形状、同间距、同原点，而且由使用者确认已经配准到同一物理位置。尺寸相同不等于已经配准。剩余厚度≤0会拒绝建模，不会截断或修补；不会隐式插值或降采样。

有限元长度为`(nx-1)*dx`，宽度为`(ny-1)*dy`，表示采样点跨度。它与以元胞数量乘间距定义的CA域宽度有一个采样间距的区别。每面原始文件、哈希、变换、单位及配置均冻结到任务。

## 关键可调项与影响

| 参数 | 物理或计算作用 |
|---|---|
| 原厚度、XY间距、原点 | 决定真实几何、剩余厚度及两面配准；不能为了通过预检随意改厚度 |
| 厚度层数 | 增加厚度方向分辨率，也增加节点、单元和求解成本；仍需网格收敛研究 |
| E、泊松比 | 控制弹性刚度、横向收缩 |
| 双线性屈服应力、切线模量 | 控制开始塑性及其后的硬化；不表示断裂 |
| MISO塑性应变—应力表 | 控制分段塑性响应；必须输入塑性应变而非未经处理的总工程应变 |
| 自由泊松/夹持/原宏边界 | 改变端部横向收缩与局部应力，比较结果前应保持边界一致 |
| 目标位移、大变形 | 决定拉伸程度及几何非线性；大位移应复核材料数据适用范围 |
| 初始/最大/最小子步数 | 控制自动步长范围、收敛及结果保存密度，满足min≤initial≤max |
| CPU核数、超时 | 影响运行资源和最长等待时间；更多核不保证更快，受模型及许可证限制 |
| 完整场输出 | 输出末步节点位移、平均等效应力、等效塑性应变，增加文件量 |
| 重启动保存频率 | 请求MAPDL保留非线性重启动文件；需要完整文件集和匹配版本，尚不提供未经验证的一键续算 |

现阶段使用八节点SOLID185实体；不包含断裂、损伤、接触、弯曲或屈曲。边长比和正体积检查不等于ANSYS单元质量验收。

## 运行与导出

先使用无腐蚀弹性板预设，点预检，再生成输入包。完成后到任务结果下载`apdl_tension_input_bundle.zip`，包含`main.inp`、节点、单元、材料/边界/求解/后处理宏、深度/残厚CSV、无损输入NPZ、预览、哈希清单及说明。

配置本机已安装的MAPDL后重启网站服务：

```powershell
$env:MAPDL_BIN = 'C:\Program Files\ANSYS Inc\v242\ansys\bin\winx64\ANSYS242.exe'
python start_server.py --port 8523
```

上面是路径格式示例，实际版本与位置以本机安装为准。GitHub保存APDL脚本，不能提供本机求解器或许可证。发现可执行文件也不代表许可证已验证。

也可将ZIP解压到英文目录，运行：

```text
run_apdl.cmd "本机真实的ANSYS可执行文件路径"
```

网页求解在独立任务目录运行，保存原始日志、退出码、耗时和实际命令。失败保留已生成的模型。输出目录已存在旧求解文件时拒绝覆盖或复用，需新建任务。

真实求解后，`force_displacement.csv`为无表头6列：时间、位移mm、加载端反力N、固定端反力N、工程应变、名义应力MPa。`nodal_results.csv`为9列：节点号、XYZ、UX/UY/UZ、平均节点等效应力、等效塑性应变。平均节点应力不代表积分点峰值。全场CSV为满足APDL单行128字符限制使用有限导出精度，原输入仍保留双精度。

## 验收边界与后续建议

求解成功需同时满足正常进程退出、无明确错误/最终不收敛日志、非空RST、完整有限CSV、TIME=1、各步位移与加载一致、两端反力平衡、应变/应力分母一致。请求完整场时缺失节点文件判失败。这里对RST检查存在与非空，完整数值主要由真实批处理及后处理CSV联合核验，不是独立的二进制RST审计。

无腐蚀线弹性自由泊松工况比较EA/L与EAδ/L；误差超过5%明确标记需复核。这个5%是初次检查阈值，不代表论文级网格收敛标准。曲线最大已保存反力不能直接称极限承载力。

本次开发环境未发现可用MAPDL程序，尚未完成真实ANSYS基准、非线性收敛或原双面数据的实算验收。过程单测中的模拟进程及测试CSV不作为研究结果。

建议按顺序继续：真实无腐蚀弹性板 → 等厚均匀腐蚀解析对照 → 单面与对称双面对照 → 真实双面配准数据 → 厚度/XY网格收敛 → 材料曲线与试验对照。正式比较前锁定材料、单位、原始截面积及边界，记录ANSYS版本、核数和许可证。高应变MISO原预设应在基础验证之后运行。
