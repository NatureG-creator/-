# 单轴拉伸：颈缩、损伤与断裂

入口：有限元耦合 → 工况预设 → **损伤断裂示例 · LS-DYNA（未标定）**。
也可在“3A · 损伤与断裂”选择 LS-DYNA / GISSMO，再填写自己的材料、网格和加载参数。
原有 MAPDL 弹性、BISO、MISO 拉伸保留；损伤默认关闭。

## 计算链

1. 读取原有单面/双面腐蚀数据，沿原有流程冻结来源和 SHA-256，建立八节点六面体。
2. 将 MISO 界面里的真实应力—等效塑性应变表写为 LS-DYNA `MAT_024` 硬化曲线。
3. `MAT_ADD_DAMAGE_GISSMO` 根据应力三轴度、塑性应变和用户的尺寸正则化曲线累积损伤；达到材料失稳指标后耦合应力退化，达到失效条件后删除单元。
4. 使用全积分实体（ELFORM=2）、显式大变形、位移控制；前90%物理时间平滑加载，最后10%保持位移。没有质量缩放。加载曲线末端继续保持，以覆盖显式时间步的小幅越界。
5. 从原生 `d3plot` 和 `binout` 读取实际坐标、反力、积分点损伤、单元存活及能量；校对二进制节点编号、原始坐标和连接关系与冻结网格一致。
6. 输出工程曲线、损伤历史、能量历史、四阶段真实变形图、断裂检查报告及完整原生文件。

单位为 N、mm、MPa、s、tonne；钢材示例密度 `7.85e-9 tonne/mm³` 对应 `7850 kg/m³`。
曲线应变为两端相对位移/原始模型跨度，名义应力为加载端总反力/原始横向尺寸与板厚之积。
比较试验时，应使试验测量标距与此口径一致，或使用原生节点位移另取引伸计标距。

## 参数与结果边界

- 塑性曲线必须单调不降，第一点塑性应变为0；不要把试验工程曲线的下降段直接作为硬化关系。
- 失效曲线是 `[应力三轴度, 局部等效塑性失效应变]`。断后伸长率不能直接作为局部失效应变。
- 临界塑性应变 ECRIT、损伤累积 DMGEXP、应力退化 FADEXP 和尺寸修正 LCREGD 需要标定。
- 默认尺寸修正倍率均为1，不代表做过网格正则化标定。更换网格须进行敏感性验证并重新检查失效参数。
- 当前新模式支持八节点六面体和自由泊松/两端夹持约束；不将未经验证的四面体转换、原脚本角点边界静默带入损伤模式。
- 无腐蚀示例显式添加2%的高斯厚度缺陷以定位颈缩。实际腐蚀形貌不额外添加这一缺陷，几何不会被隐式修改。
- 数值阻尼默认关闭。示例使用质量比例数值阻尼以衰减断裂后的波动，系数及耗能明确记录；它不是标定的材料粘性。必须同时检查降低阻尼和延长加载时间的影响。
- 原始反力保留正负号；断裂后的波动、负反力和卸载波不被平滑、裁剪或补零。反力数据库按原生场结果时刻线性对齐，原始 binout 保留。
- “参数已标定”只是用户提供的数据来源声明，网站不据此声称已经独立验证。

## 如何判断完成

“目标加载完成”与“完整断裂”分别判断。数值断裂检查需要：有原生单元失效、存活网格中两端不再连通、末步拉力低于峰值5%。
单个单元失效、曲线峰值、求解器中止或单元畸变都不能单独认定为断裂。

颈缩筛查使用失效前截面的面积收缩比，并与其他内部截面比较；相对比小于0.9仅为定位局部非均匀收缩的指标，不是通用材料失稳准则。
断裂前动能/内能、阻尼耗能/内能以及反力不平衡/峰值的5%阈值用于数值筛查，仍需加载速度敏感性和网格敏感性验证。

## 环境与复现

需要已安装且可授权运行的 LS-DYNA，自动在 MAPDL 安装目录查找 `lsdyna_dp.exe`，或设置 `LSDYNA_BIN`。
许可证在真实求解时验证，程序文件存在不代表授权可用。

在已经安装网站基础依赖的 Python 中，安装锁定的二进制读取子集，避免替换原科研环境的数值包：

```powershell
python -m pip install --no-deps -r requirements-fracture.txt
python launch.py --no-browser
```

完整独立复现（会进行三次真实求解，输出目录必须尚不存在）：

```powershell
python scripts/validate_fracture.py --output D:\research\fracture-validation-new
```

验收证据见同目录 `validation/20261026-gissmo/`。全部为演示材料，未宣称真实钢材的断裂参数已经验证，也未宣称网格独立性已经验证。
