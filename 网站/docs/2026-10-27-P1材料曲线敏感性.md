# P1：真实材料曲线、网格与加载时间敏感性

网站新增 `POST /api/apdl/sensitivity`。请求提供已完成的无腐蚀 MISO/LS-DYNA 源任务编号，服务端冻结源任务的材料曲线和 GISSMO 参数，顺序运行三组网格与两个物理加载时间。

默认网格为 `21×3×2`、`41×5×4`、`61×7×6`（`nx×ny×厚度单元层数`），默认加载时间为 `0.002 s` 与 `0.004 s`。每个工况保留独立任务目录、原生 d3plot/binout、断裂阶段标记、能量/阻尼筛查和完整断裂判定。

报告输出 `sensitivity_summary.csv`、`sensitivity_report.json` 和 `sensitivity_metrics.png`，对比峰值拉力、峰值工程应变、首次删除、承载路径断开位移、末步/峰值拉力比、动能/内能、阻尼耗能和准静态筛查。

材料来源状态明确写为“真实材料曲线已应用、结构响应尚未反演校准”。没有试验力—位移或 DIC 目标时，峰值接近不能被称为结构响应已标定；GISSMO 失效曲线、ECRIT、FADEXP 和尺寸正则化仍需试验标定。
