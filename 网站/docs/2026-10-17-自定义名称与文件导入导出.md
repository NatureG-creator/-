# 自定义名称、本机导入与成果导出

各模块标题下增加“任务名称与成果位置”。填写名称后运行，任务页与历史记录使用这个名称；任务 ID 保留。成果目录可填本机绝对路径，也可点“选择目录…”使用本机目录对话框。取消对话框保持原值；无法使用对话框时可手动填路径。

## 各模块输入

| 模块 | 本机输入入口与格式 |
| --- | --- |
| 实测点云 | 参考点云、腐蚀细节点云两个文件按钮；TXT / CSV / TSV / XYZ |
| 腐蚀演化 | 六指标 MAT / CSV / TXT / TSV / XLSX；配置 JSON |
| 性能对比 | 新增“从电脑导入模拟配置 JSON”；接受第二部分导出的完整配置及 N×6 目标，可切回第二部分当前配置 |
| APDL 建模与拉伸 | 沿用逐面的 MAT / CSV / TXT / TSV、外部 NPZ、完整三份或六份 XYZ 坐标入口 |
| 原有限元表面导出 | 新增“使用已完成任务 / 从电脑导入文件”；MAT 的二维 Z_filled / F_filled（mm），或含 perfect_a / 支持的 a_sd 的模拟 NPZ |
| 单变量、双自变量拟合 | 沿用各页表格上传与预览选列；CSV / TXT / TSV / XLSX / MAT |
| Origin 绘图 | 使用拟合结果；新绘图任务也有名称与导出目录控件 |

支持格式不表示任意内容都能通用。所有科学输入仍通过原模块校验和冻结。原有限元表面导出同时含两个变量时，所选输入变量会传给实际导出器。

## 成果位置与重命名

- 目录留空：原任务目录保存成果，下载按钮仍可用。
- 目录非空：计算完成后自动复制成果到 `成果_名称_任务ID_随机后缀` 子目录。成果包含 outputs、冻结 spec、状态、可用日志及任务名称记录；内部科学文件名保持既有接口。
- 结果页新增“本次任务：重命名与另存成果”。可修改名称、目录并保存，或在任务结束后点击“导出到此目录”。历史任务无需重新计算。
- 重复导出生成新子目录，保留之前副本。已有导出副本不会因之后改名而自动搬动。
- 复制失败会显示错误及保留的部分路径；原计算结果仍为完成，不因另存失败而丢失。修改目录后可重试。复制进程异常退出也可重试。
- 运行中禁止手动复制成果，防止取到仍在写入的文件。失败或中断任务结束后可手动导出现有部分成果。
- 目录不能位于网站内部 runtime。导出文件夹在运行网站的本机磁盘创建；浏览器单个文件下载仍遵从浏览器下载设置。
- 命名与目录保存于独立 `task_io.json`，重命名不修改冻结科学参数或检查点。老任务兼容原有 case_name。

## 验证与应用

2026-10-17：63 项相关后端/接口测试通过；103 项前端测试通过，相关 JavaScript 语法检查通过。

使用独立临时 runtime 做了浏览器验收：选择 MAT、填写名称与目录、生成输入包并自动复制 6 个成果文件、重命名并再次另存；从电脑导入 CSV 拟合、自动复制 26 个成果文件；刷新后历史名称保留，Origin 新任务控件存在。测试未运行 MATLAB/MAPDL/Origin 求解或真实绘图。目录选择接口与取消结果有组件检查，本机 tkinter 可导入；未代用户选择真实研究成果目录。

快捷启动入口使用代码版本校验：旧后台不再因目录相同就被复用；首选 8537，端口被占用时自动选择空闲端口并记录实际地址。保留原任务 runtime，原运行服务及研究进程不被停止。后续源码更新后重新双击桌面快捷方式，可打开新版服务。
