# 通用拟合验收记录

## 实现范围

第四独立运行区支持CSV/TXT/TSV/XLSX/MAT与粘贴表格，单X单Y、分类独立拟合；内置显式函数与安全自定义公式，提供指标选择、验证方式、推荐依据、输入行审计和耗时。最佳函数仅限本次候选及验证规则，不宣称发现唯一真实规律。

输出包含数值CSV、参数与指标JSON、拟合和诊断图、PNG/TIFF/SVG/PDF、输入与输出哈希清单、ZIP及Origin导入脚本。原腐蚀模拟、MATLAB科学程序、APDL建模规则和49点材料曲线未修改。

## 验证证据

- 后端全量：323项通过，183.198秒；命令为 `python -B -m unittest discover -s backend/tests -p 'test*.py' -q`。
- 前端全量：79项通过；命令为 `node --test frontend/tests/*.test.mjs`。
- 真实浏览器与独立worker：18点合成数据比较4个候选，推荐线性模型，显示2幅结果图并下载ZIP；最新验收任务为 `065cd18adb624c22`。
- 上传数据保留 `001` 与 `1` 两个不同分类；8行数据预检得到2组。浏览器未记录页面脚本异常。
- 已下载验收ZIP逐项核对29个文件的SHA256；图形四格式、CSV、冻结输入和交换脚本均由实际任务生成。验收数据均为合成数据，不作为科研结论。
- 数值反例覆盖极小/极大量纲、较大偏置的小曲率、复数拒绝、逐候选异常隔离、定义域边界与区间失败。时间验证按更早X训练，分组验证按独立验证组划分，失败折不进入自动推荐。
- 数据测试覆盖分类文本、内部空行审计、损坏XLSX/MAT，以及输入冻结；图形测试覆盖无效区间说明、路径安全和输出归档。
- 独立数值与整合审阅提出的问题均已修复，最终审阅无剩余Critical/Important问题。

两轮全量回归曾遇到Windows状态文件瞬时占用。状态读取现仅对PermissionError进行有上限的短暂重试；持续权限错误及损坏JSON仍报错。新增3项测试验证该行为，修复后上述全量回归通过。

## 仍需区分的能力

- Origin交换脚本已经生成，本机未安装Origin，尚未进行真实Origin联动验收。

- 置信/预测带仅在满足当前统计假设时生成；加权、稳健损失、时间或分组验证等情况保留不可生成原因。
- 网页在本机服务运行；未发布新的远程Sites网站。运行目录、上传数据、日志和验收截图不提交GitHub。
