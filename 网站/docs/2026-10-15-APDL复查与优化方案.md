# APDL模块详细复查与优化方案

复查日期：2026-10-15。代码基线：`5ca474c85cb9ac17ab4cc1abea674698d0bc02d3`。

本轮范围为当前第三部分：原GitHub宏与预设、单双面几何、来源读取、网页操作、输入包、MAPDL执行及结果校核。只进行了审阅、测试与反例验证，未修改生产代码、原始科研数据或运行真实MAPDL。

## 结论与证据边界

1. 原49点MISO曲线逐项一致；原角点约束正确映射；新旧双面装配在对应采样下相差整体Z平移。节点、单元编号发生变化，不能以命令文件逐字相同作为判据。
2. 新增的单面、其他边界和材料选项仍属于扩展功能。原宏没有提供这些扩展的实算验收证据。
3. 本轮复跑APDL专项42项、前端全量56项，均通过；另外用构造反例发现当前测试未覆盖的缺口。之前194项后端回归通过不等于真实ANSYS数值已验证。
4. 本机仍未定位可用MAPDL程序，无法声称原宏与网页生成模型的真实求解结果一致。
5. 应先修来源一致性、强化结果校核和停止闭环，再完成真实基准；性能与展示优化随后实施。

优先级：P1为正式研究使用前应处理的问题；P2为紧随其后的可靠性、解释性或性能提升。待MAPDL验证的风险单独标识，不当作已发生的实算故障。

## 二、P1：来源任务切换后可能带着旧阶段或旧文件

位置：`frontend/apdl.mjs:40–48,111,115,129`。

已复现：选择任务A的阶段2，再改选同类型任务B；B只有阶段1和最终文件。界面显示默认“最终simulation.npz”，请求却仍携带`source_stage:2`。实测来源的`old.mat`切换到只有`new.mat`的任务，也会保留旧`source_file`。

影响：轻则提交失败；新任务恰有同名输出时，界面与实际选取文件可能不同。

方案：

- 更换`source_job_id`时清除旧阶段和文件；新任务明细返回后，只保留确实存在的选择。
- 下拉框与草稿使用同一状态，避免只改变显示而请求仍用旧值。
- 提交前展示逐面任务、阶段、文件、变量、SHA和物理尺寸的确认摘要。

验收：A阶段2→B最终、A旧MAT→B新MAT、同名文件跨任务、快速切换任务均有回归；请求与页面显示逐项一致。

## 三、P1：结果校核需要从“格式正确”提升为“相互一致”

位置：`backend/apdl_solver.py:214–276`及`tests/test_apdl_solver.py`。

以下是合成测试文件的反例，不是已经运行ANSYS得到的研究结果：

- 只有1字节的`corrosion.rst`，配合法曲线，仍能通过目前的非空检查。
- 8节点坐标整体偏移12345 mm、节点位移与应力全为0，但曲线末位移为0.1 mm、反力24720 N，仍可能标记`passed`。
- 弹性夹持工况两端反力及名义应力均为0，只要相互平衡，其余字段匹配，仍能通过现有校核。

这说明验证器存在交叉检查盲点，不能据此断言真实ANSYS已经算错。当前真实执行还要求进程、日志、输出联合检查，这些保护应保留。

方案：

1. 读取真实RST的网格、结果集及末步时间，并与输入和CSV对应；若暂不支持目标版本的RST读取，明确标记`rst_unverified`，不能称完整数值验收通过。
2. 按节点ID核对原始坐标、固定端UX、加载端UX和角点约束；加载端末位移应与曲线末行一致。容差考虑节点CSV的E13.5导出精度。
3. 对当前无断裂、正位移拉伸模型的零承载提出异常；反力符号约定先由真实平板标定，再检查异常符号。
4. 分开显示：进程完成、目标载荷达到、文件完整、场/曲线一致、材料覆盖、网格质量、原宏对照。只对确实执行的检查给“通过”。

验收：随机/截断RST、其他模型RST、错坐标、全零节点场、错误端部位移、零承载、跨任务文件混用均拒绝或明确降级；合法真实平板和弹塑性结果通过。

## 四、P1风险：原11 mm位移可能超出材料表覆盖范围

位置：`backend/apdl_presets.py:17–21`、`apdl_geometry.py:68–85`、`apdl_deck.py:75–84`。

原采样跨度长57.6 mm，加载11 mm：

```text
全长工程应变 = 11/57.6 = 0.190972
均匀拉伸真应变估算 = ln(1+11/57.6) = 0.174770
材料末点塑性应变 = 0.137798
末点弹性应变估算 = 621.16/185226 = 0.00335352
末点总真应变估算 ≈ 0.1411515
对应均匀延伸估算 ≈ 8.73 mm
```

这些计算提示覆盖风险，不能证明实际腐蚀模型每个积分点必然超界。[ANSYS材料参考](https://ansyshelp.ansys.com/public/Views/Secured/corp/v251/en/ans_mat/amp8sq21dldm.html)说明，MISO表外使用最近表点，末点后表现为完全塑性。

方案：保持原49点和原预设不动；提交前提示覆盖估算，求解后报告每子步积分点累积塑性应变最大值、首次超表子步及超表位置。材料曲线定义应与大变形设置对应，不能仅因求解收敛就认定材料数据足够。

当前最终平均节点`EPPL,EQV`不能普遍替代累积`NL,EPEQ`来判断表覆盖；[官方等效应变说明](https://ansyshelp.ansys.com/public/Views/Secured/corp/v252/en/ans_thry/thy_post12.html)限定二者关系的适用条件。保留现有字段，另加所需历史量。

验收：用无腐蚀均匀板先做同长度/同材料/11 mm实算，观察是否超界；再检查腐蚀热点。扩展材料数据需来自试验或经校准的本构模型，不自动延长或平滑曲线。

## 五、P1：异常退出和停止必须形成进程清理闭环

位置：`backend/apdl_solver.py:59–64,152–165`、`backend/job_service.py:491–499`。

静态与mock复现确认：父进程`poll()!=None`时，清理函数直接返回，不再处理可能尚在运行的后代；Windows的`taskkill`返回失败也未被检查。父进程结束不能证明全部计算子进程结束。

方案：

- Windows使用适合目标ANSYS启动方式的Job Object或独立监管机制，记录求解器/后代PID及创建时间。
- 记录停止命令的返回码及输出，核验所有已登记进程退出；失败显示“停止未完成”，不显示确定停止。
- 任务因网页worker异常退出时，也由监管者处理求解进程。目标ANSYS及MPI子进程是否能完整加入监管，需要实机验证。
- APDL停止消息应说明已保留的输入/已生成结果及重启动条件，不沿用CA“完整个体已保存”的用语。

[Windows Job Objects官方说明](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)给出了成组监管及关闭句柄时终止进程的机制，也指出子进程脱离策略的限制。

验收：用自有测试launcher模拟“父进程先退出、子进程继续”“停止权限失败”“worker意外退出”等；既不能留下未报告的计算后代，也不能误停其他任务。再用真实MAPDL验证。

## 六、P2：配准确认、输入框状态和模拟继承值

位置：`frontend/apdl.mjs:111,118,123–130`。

已确认的界面缺口：

- 配准勾选后换来源或改翻转/坐标映射，确认仍保留。原确认不应覆盖新组合。
- 当前上传正常完成时重绘来源卡片，可能覆盖用户尚未失焦的间距输入；已用实际mount函数与延迟响应复现。
- 实测来源改成模拟来源，旧μm/height/间距仍可能显示在禁用框中，但实际请求删除间距，后端按模拟真实尺寸和mm/depth处理。实际执行规则正确，界面值却可能误导。

方案：配准确认绑定两面来源SHA、阶段/文件/变量、映射及物理坐标签名；任一相关项变动要求重新确认。输入事件即时同步草稿，避免重建正在编辑的控件。模拟来源显示已解析的只读实际单位与间距，或明确标为“由来源继承”。

验收：换源/翻转/裁剪后确认失效；上传返回前输入但不失焦，值与请求仍保留；实测→模拟后页面显示值与预检实际值一致。

## 七、P2：Python预检的网格质量指标不足

位置：`backend/apdl_geometry.py:172–180,199–201`。

已复现：

```python
bottom = [[0., 2.], [2., 4.]]
top = [[4., 2.], [2., 0.]]
# 原厚度6 mm，dx=dy=0.001 mm，厚度1层
```

这个结构化单元剩余厚度为2 mm，边长比约1，却极度剪切，角点scaled Jacobian约2.5e-7。单看边长比不能提前识别。

现有APDL已经包含`CHECK`，默认形状检查也已开启，不能说求解器完全没有质量检查。[SHPP官方说明](https://ansyshelp.ansys.com/public/Views/Secured/corp/v242/en/ans_cmd/Hlp_C_SHPP.html)列出了形状检查及摘要输出。

方案：增加scaled Jacobian、角度/翘曲等预检，输出最差单元ID和位置；保存MAPDL形状检查摘要。不得为了成功运行关闭或随意放宽质量限制。

验收：上述畸变反例提前预警；规则平板指标正常；实际形貌再做网格收敛。预警阈值需结合单元类型和目标精度确定，不把单一阈值当论文级证明。

## 八、P2：预览会漏极端点，横坐标也需按真实采样显示

位置：`backend/apdl_service.py:253`、`frontend/apdl.mjs:136–137`。

已复现：200×200矩阵只有最后一个点深度1 mm，其余0。按步长3抽样后预览最大值变成0，最后采样索引198而原末点是199。82列时也会遗漏末列，并把保留点拉伸到完整模型长度。

影响仅在预览，完整几何和统计仍使用原矩阵；但用户可能看不到最危险坑位。

方案：采样必须保留端点并返回真实XY坐标；剖面从真实中线单独提取；热图结合极值位置标记，或分块极值表示并说明语义，不把近似图当精确原图。显示上下表面、最薄位置、轴向箭头与物理单位。

验收：82/160/193/200等尺寸的端点、坐标和中线一致；孤立边缘深坑有明确标记，预览不改变任何求解输入。

## 九、P2设计风险：裁剪后的局部坐标与全局坐标要明确

位置：`backend/apdl_service.py:80–89,140–143,219–222`。

原GitHub预设的裁剪后重新建立局部坐标有明确兼容依据，应保留。普通来源如果想保持原物理坐标，则需考虑被裁去的列数。

例：2×5和2×7两面均中心裁3列，分别裁到[1,4)和[2,5)，但目前都可保留同一个输入原点。若用户按全局坐标理解，它们对应的区域不同；若明确作为局部重定位，则需要外部配准确认。这是坐标语义需明确的设计风险，不直接判为原宏兼容规则错误。

方案：提供“原宏局部坐标”和“保留原全局坐标”策略；后者按裁剪轴、起始索引和间距更新原点。显示原图裁剪框、最终坐标范围及两面叠加检查。

验收：原预设与原MATLAB几何仍等价；全局裁剪保留真实位置，不同区域的双面不能仅凭同形状就通过。

## 十一、性能优化：先测量，再减少重复工作

目前一次“提交”通常经过：网页自动预检构建几何→创建任务再次预检构建→worker再读来源并构建。预检发生在真正任务排队之前。

本轮在193×60、8层的104220节点/90624单元上测得单次几何构建约0.048–0.049秒。因此这个规模只减少重复几何构建，收益约0.1秒量级，不能承诺ANSYS求解明显提速；大文件读取、绘图与真实求解须分别测量。

建议：

1. 把来源检查、统计、完整网格分开。预检只算必要二维统计及预算，worker生成一次完整网格。
2. 用源SHA、变量、映射及适配器版本作为缓存键，冻结已转换二维深度；保留原文件与哈希，不削弱修改检测。
3. MAT只读取所需变量；大CSV/节点统计和文件哈希使用分块处理，限制预检同时占用的内存。完整曲线留文件，网页用有说明的预览。
4. 显式提供结果保存策略：各子步力位移需要保留；完整场可按研究需求选择末步或更多子步。任何减少输出都必须记录，不能静默删除所需历史量。
5. MAPDL可用后用同模型比较1/2/4核，记录实际CPU/许可证/求解模式及输出；不根据核数预先宣称谁最快。
6. 不默认降低XY采样、厚度层数或放宽收敛要求。网格简化必须作为明确选项，通过几何误差、反力和热点应力收敛验证。

## 十二、科研比较定义：夹持、标距与应力分母

当前全长位移/模型长度和反力/原宽×原厚有明确数学定义，并非计算公式错误。但它们不自动等于试验引伸计应变或净截面应力。

建议增加可选引伸计截面与独立标距，明确夹持段和腐蚀区域；分别保存全长应变、标距应变、名义应力，净截面量另列。不要只因两条曲线形状相似，就认为加载、材料和试验定义一致。

验收：规则平板全长与局部标距结果一致；腐蚀局部化产生可解释差异；与试验比较时使用一致的标距、原始截面和位移测量定义。

## 建议实施顺序与验收关口

| 阶段 | 工作包 | 验收关口 |
|---|---|---|
| 1 | 换源清理、输入不丢失、继承值、配准签名 | 所见来源与实际请求完全一致，相关反例回归通过 |
| 2 | 结果交叉校核、状态分层、停止闭环、失败计时 | 矛盾/损坏结果不能完整通过，异常退出无未报告后代 |
| 3 | 接入实际MAPDL与原宏对照 | 同一小数据两套模型，统一版本/材料/边界后比较几何、力位移、应力和应变 |
| 4 | 材料覆盖、网格质量与收敛、试验定义 | 报材料超界与坏单元，完成有目标精度的网格/标距验收 |
| 5 | 预览、配置与完整归档、性能 | 图坐标准确、配置可恢复、归档可追溯；提速同时满足结果一致性 |

真实数值验收顺序：无腐蚀弹性板→均匀单面腐蚀→均匀双面腐蚀→同一非均匀双面原宏对照→原49点MISO非线性→网格收敛与实际试验。均匀厚度减少的线弹性参考用实际剩余截面，非线性或夹持工况不能直接套用简单EA/L结论。

软件异常测试和科学验证应分开保存。原宏复现也不能证明原材料曲线适用于全部新几何与新加载；这两个验收问题都要独立回答。
