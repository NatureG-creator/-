# 快捷启动版本与端口

双击桌面的“腐蚀研究工作台”打开新版网站。首选端口为 8537；端口已占用时在之后 30 个端口中寻找可用项。不要将书签中旧端口当作固定地址。

启动器通过 `/api/health` 校验网站目录与源码摘要。服务在启动时记录代码摘要，只有与当前源码一致时才会复用。源码改动后再次启动会选择空闲端口，旧服务及其计算进程不会被终止。

本机桌面包装脚本继续传入原有数据 runtime，保留历史任务和成果，并将实际打开地址写到快捷启动文件夹的 `最近打开地址.txt`；runtime 的 `service.json` 保存实际端口。GitHub 中不保存本机绝对路径、软件安装目录或研究数据。

其他电脑可在网站目录运行 `python launch.py`；命令行可用 `--port` 指定首选端口。程序接口 `launch(runtime=...)` 可指定已有任务目录。启动时会检查当前 Python 的项目依赖。

验证包含旧后端不能复用、源码改动使版本失效、研究数据不影响版本、启动快照不随磁盘变化而更新，以及自定义 runtime 传递。版本校验不会迁移或修改已有科学结果。
