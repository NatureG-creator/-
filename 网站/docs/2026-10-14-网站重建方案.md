# 腐蚀研究工作台重建方案

本次实施依据本对话中已经确认的功能要求、2026-10-13的详细复核建议，以及2026-10-14“重新生成并上传GitHub”的指令。继续实施已有设计，不重新要求用户确认。

## 范围与边界

- 网站位于本仓库`网站/`；科研原目录只读，全部计算调用网站独立引擎副本。
- 两个主要运行区依次是实测点云六指标、多阶段模拟；任务记录和结果区辅助两条流程。
- 点云表单覆盖`step00_corrosion_config.m`的全部参数并解释作用。几何依据输入实际范围、网格间距和可调参考区列数，不假定扫描为60或190 mm。保留齐平、参考面、坑识别、分水岭、对数和六指标定义。
- 模拟表单覆盖`unified_config.py`的全部配置，注明影响阶段与运行器实际支持范围；路径映射为任务目录，不能把未使用的后处理参数描述为已经参与CA。
- 输入支持XYZ文本点云、MAT及六列CSV/TXT/TSV目标，MAT自动检查行列、变量和转置，非有限值返回具体位置。
- 固定或自动种子、单/多阶段、多工况、实际后端、资源估算、读取/计算/检查点/绘图/导出计时、进度与日志、数值/图片下载、配置导入导出、历史载入必须可操作。
- 严格模式使用NumPy固定随机状态，按完整个体记录和每代检查点恢复，未完成个体重算。使用不可变最优状态引用和原子快照，验证中断恢复与原GA及连续运行一致。高速模式不承诺相同种子跨后端逐位一致。
- 先保存阶段数值数据，再生成可选图；图片失败不阻止数值导出。阶段编号不等于腐蚀天数。
- 专业中文界面、响应式、明确单位、真实计算流程示意和收敛/误差展示；不引入虚构数据或伪计算。
- 本机运行MATLAB/Python；GitHub保存源码，不能用静态托管代替本机计算服务。
- 上传既有远端`https://github.com/NatureG-creator/-`；不上传`.runtime`、临时测试数据、日志、密钥。提供一键打开和一键同步脚本。

## 实施与验收

1. 基线：11项网站测试通过；起始提交`e563984`。源目录不可用时保留可访问的仓库副本，源码按现有独立副本核对。
2. 输入与参数：完整目录、类型正确、无尺寸文案硬编码、MAT变量和预览、无效参数提交前拒绝。
3. 计算：严格模式对照原GA、阶段间传递和中断恢复；检查点损坏回退、配置/引擎不匹配拒绝；数值优先导出和逐阶段预览。
4. 网页：表单与导入导出单一状态，文件联动、固定/随机种子、运行/停止/恢复、日志、目标与误差表、图片、下载、历史载入。
5. 发布：实际HTTP和浏览器操作极小任务；运行回归测试；审核git差异与待上传文件；提交并正常推送远端，验证远端提交。
