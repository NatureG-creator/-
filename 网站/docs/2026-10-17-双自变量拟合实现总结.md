# 双自变量拟合实现总结

## 已实现

- 新增独立的 `Y = f(X1, X2)` 拟合模式，不改变原有单 X、单 Y 模式。
- 支持 CSV、TXT、TSV、XLSX、MAT 和网页粘贴表格。
- 支持 X1、X2、Y 和可选分类列；每个分类组独立拟合。
- 支持二元线性、二元交互项和二元二次响应面模型。
- 预检会根据列名、单调性、正值和样本规模生成数据画像、候选模型与推荐图形；推荐不强制覆盖手动选择。
- 支持验证 RMSE、验证 MAE、训练误差、R²、调整 R²、AICc、BIC。
- 支持随机 K 折交叉验证、随机种子、参数满秩检查和共线性失败说明。
- 新增三维响应面、XYZ 网格 CSV、残差 CSV、模型排名 CSV、X1/Y 与 X2/Y 切片图。
- 新增 `origin_import_multivariate.py` 和 Origin XYZ 交换说明；未安装 Origin 时仍可使用 CSV。
- 双自变量任务沿用现有任务队列、冻结输入、SHA256 校验、进度和结果下载。

## 输入格式

```csv
X1,X2,Y,Group
0.1,10,2.3,A
0.2,10,2.8,A
0.1,20,3.1,B
0.2,20,3.7,B
```

## 科学边界

- 当前双自变量模式是响应面回归，不自动推断腐蚀机理或物理定律。
- 自动推荐仅在当前候选模型、数据范围和验证规则内有效。
- 数据范围外曲面属于外推，需要结合试验或有限元结果判断。
- 自定义二元公式接口已预留，首版只对参数线性可识别的安全公式生成数值结果；复杂非线性参数公式暂不生成曲面网格。
- Origin 脚本需要本机已安装 Origin、许可证和兼容 `originpro` 环境，网页不把脚本生成当作 Origin 实机验证。

## 验证

- `backend/tests/test_fitting_multivariate.py` 覆盖交互项自动选择、常量自变量、长度不一致和选项边界。
- 原单变量拟合测试继续使用原模块和原接口。
