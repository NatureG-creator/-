## 下载大型归档

超过普通 Git 文件大小限制的归档通过 Git LFS 保存。完整获取数据：

```powershell
git clone https://github.com/NatureG-creator/-.git
cd -
git lfs pull
```

如果只下载 GitHub 网页的源码 ZIP，LFS 文件可能仅包含指针，请使用上述方法取得原始归档。
