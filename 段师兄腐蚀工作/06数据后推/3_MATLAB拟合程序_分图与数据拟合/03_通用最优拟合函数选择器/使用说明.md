# MATLAB通用最优拟合函数选择器

## 1. 最简单的使用方法

1. 在MATLAB中将“当前文件夹”切换到本程序所在文件夹。
2. 打开 `run_best_fit_selector.m`。
3. 直接点击“运行”，在弹出窗口中选择数据文件。
4. 程序自动识别数据列，并为每个指标分别弹出拟合函数选择窗口。
5. 输入文件旁边会生成 `<输入文件名>_自动拟合结果` 文件夹。

也可以在 `run_best_fit_selector.m` 顶部直接设置：

```matlab
data_file = 'D:\your_folder\your_data.xlsx';
export_figures = true;
formula_digits = 4;
```

自动识别入口等价于：

```matlab
result = best_fit_selector_auto(data_file,[],true);
```

若希望像运行入口一样，为每个指标分别弹出选择窗口：

```matlab
result = best_fit_selector_auto(data_file,[],true,"prompt",4);
```

每个指标均可独立选择：

1. 自动选择最优函数；
2. 线性函数；
3. 二次函数；
4. 幂函数；
5. 对数函数；
6. 指数函数；
7. 指数饱和函数；
8. 双曲线饱和函数；
9. 连续两阶段幂函数；
10. 两阶段对数模型；
11. 均值模型。

选择“自动选择最优函数”时，程序按AICc比较9种候选函数；选择具体函数时，只拟合并输出该函数。

## 2. 自动识别规则

- 有 `Eta` 时，将其作为质量损失率横坐标。
- 只有 `EtaPercent` 时，程序自动计算 `Eta = EtaPercent/100`。
- 自动查找 `EpsilonH`、`EpsilonU`、`EpsilonF`、`E_MPa`，存在几项就分别拟合几项。
- 自动查找 `Fy_MPa`、`Fu_MPa`、`Ff_MPa`、`StrengthRatio`，存在几项就分别处理几项。
- 默认自动模式下，`Fy_MPa`、`Fu_MPa`、`Ff_MPa` 比较9种候选函数；`StrengthRatio` 默认计算均值和标准差。
- 普通数据包含 `x`、`y` 时，按通用二列数据拟合。
- 没有上述列名但恰好只有两列数值时，按第1列为x、第2列为y处理。
- 检测到 `Material,Metric,Model,Intercept,Slope,R2,RMSE,Formula` 时，判定为已经生成的拟合结果表并停止运行。

四个力学指标的含义：

- `EpsilonH`：硬化应变；
- `EpsilonU`：极限应变；
- `EpsilonF`：断裂应变；
- `E_MPa`：弹性模量，单位MPa。

四个强度指标的含义：

- `Fy_MPa`：屈服强度，单位MPa；
- `Fu_MPa`：抗拉强度，单位MPa；
- `Ff_MPa`：断裂强度，单位MPa；
- `StrengthRatio`：强屈比 `Fu/Fy`，输出均值、标准差和均值统计图。

每个指标写入独立子文件夹，同时在总目录生成 `自动拟合汇总.csv`。

## 3. 输入数据格式

支持 `.xlsx`、`.xls`、`.csv`、`.txt`、`.dat` 和 `.mat`。

- Excel/CSV/TXT：两列数据，推荐列名为 `x` 和 `y`。
- MAT：默认必须包含数值变量 `x` 和 `y`。
- `x`、`y` 必须长度相同。
- 程序自动删除 `NaN` 和 `Inf`，再按 `x` 升序排列。
- 至少需4个有效数据点；两阶段函数至少需6个点。

`example_fit_data.csv` 是可直接运行的示例。

如仍需手动指定列名，可以直接调用原函数：

```matlab
result = best_fit_selector(data_file,'Eta','EpsilonH',[],true);
```

手动指定单个函数的调用形式为：

```matlab
result = best_fit_selector( ...
    data_file,'Eta','EpsilonH',[],true,'线性函数');
```

## 4. 自动比较的9种函数

1. 线性函数：`y = a*x+b`
2. 二次函数：`y = a*x^2+b*x+c`
3. 幂函数：`y = a*x^b`
4. 对数函数：`y = a*ln(x)+b`
5. 指数函数：`y = a*exp(b*x)`
6. 指数饱和函数：`y = a*(1-exp(-b*x))+c`
7. 双曲线饱和函数：`y = a*x/(b+x)+c`
8. 连续两阶段幂函数：

```text
x < xc  : y = a*x^n1
x >= xc : y = a*xc^(n1-n2)*x^n2
```

9. 两阶段对数模型（严格对应文献公式）：

```text
x < x1  : ln(y) = a*ln(x)
x >= x1 : ln(y) = a*ln(x1)+b*ln(x/x1)
```

其中第8种含有独立倍率系数，是更一般的扩展形式；第9种不含独立倍率系数，与文献图片中的形式一致。

两阶段函数会自动搜索转折点 `xc`，并保证转折点左右连续。

## 5. 模型选择原则

程序以 `AICc` 最小作为默认最优模型。`AICc` 同时考虑拟合误差和参数数量，并对小样本进行修正，可避免只因参数更多就把复杂模型误判为最优。

评价表同时给出：`R2`、调整 `R2`、`RMSE`、`SSE`、`AIC` 和 `AICc`。

为保证比较公平，所有参与排名的模型必须使用同一组数据。如果数据含有非正 `x` 或非正 `y`，不满足定义域的幂函数、对数函数或两阶段函数会整体跳过，不会偷偷删除部分数据后参与排名。

## 6. 输出文件

- `模型拟合评价表.csv`
- `最优拟合函数.txt`
- `清洗后的拟合数据.csv`
- `全部模型拟合对比图.png/.tif/.pdf/.fig`
- `最优模型拟合图.png/.tif/.pdf/.fig`
- `最优模型残差图.png/.tif/.pdf/.fig`

PNG和TIF为600 dpi，PDF为矢量图，FIG可在MATLAB中继续修改。拟合曲线只在已输入的 `x` 范围内绘制，不默认向范围外外推。

## 7. 给01、02、04、05、06提供统一拟合结果

公共函数 `fit_grouped_dataset.m` 会按“材料+指标”分别调用本文件夹的拟合核心，并输出：

- `统一拟合结果.mat`：保存完整双精度参数，绘图曲线使用此参数计算；
- `统一拟合结果.csv`：保存模型名称、P1-P4、R2、RMSE、AICc和显示公式；
- 各材料、各指标的独立拟合结果子文件夹。

`formula_digits` 只控制公式和图中文字保留几位小数。例如：

```matlab
formula_digits = 2; % 公式显示2位小数
formula_digits = 4; % 公式显示4位小数
formula_digits = 6; % 公式显示6位小数
```

无论显示几位，MAT文件和曲线计算始终使用完整精度，因此不会因显示舍入改变拟合曲线。

## 8. 常见报错

- `BestFit:MissingColumn`：列名或列号不对，检查 `x_column`、`y_column`。
- `BestFit:NonNumericData`：选中的列不是纯数值。
- `BestFit:InsufficientData`：清洗后的有效数据点少于4个。
- `BestFit:NoValidModel`：所有候选模型都拟合失败，需检查数据范围和数值量级。
- `BestFit:ResultFileNotRawData`：选择的是拟合结果参数表，不是原始实验数据。
- `BestFit:UnrecognizedSchema`：列名和数据列数均不符合自动识别规则。
