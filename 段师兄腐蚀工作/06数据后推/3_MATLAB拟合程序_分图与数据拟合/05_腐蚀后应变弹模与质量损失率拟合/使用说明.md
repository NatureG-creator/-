# 腐蚀后应变弹模与质量损失率拟合

## 运行方法

打开 `plot_strain_modulus_fits.m`，修改：

```matlab
fit_target = 'Q370NH'; % 只生成Q370NH
fit_target = 'Q355';   % 只生成Q355
fit_target = 'both';   % 生成两种钢材对比图
model_choices = "auto"; % 使用03自动选择最优函数
formula_digits = 4;      % 公式参数显示4位小数
```

`Q370` 也可作为 `Q370NH` 的输入别名。

## 数据和计算方法

- 原始数据在 `strain_modulus_data.csv`。
- 每种钢材使用9个腐蚀时间、1号和2号试件，共18个散点。
- 硬化应变、极限应变、断裂应变和弹性模量均由03文件夹比较9种候选函数并选择AICc最小的模型。
- CSV中 `EtaPercent` 保存百分数，回归及此组图的横坐标使用 `eta=EtaPercent/100`。

程序根据CSV实时重新计算模型、完整参数、R2、RMSE和AICc，不硬编码参考图的旧公式。完整参数保存在 `03_统一拟合结果/统一拟合结果.mat`，公式小数位只影响显示。

## 输出

程序分别生成：

- 硬化应变拟合图；
- 极限应变拟合图；
- 断裂应变拟合图；
- 弹性模量拟合图。

每张图同时输出 `.png`、`.tif`、`.pdf`和 `.fig`，并生成拟合参数CSV和绘图数据CSV。
