# 腐蚀后强度指标与质量损失率拟合

## 运行方法

打开 `plot_strength_property_fits.m`，修改：

```matlab
fit_target = 'Q370NH'; % 只生成Q370NH
fit_target = 'Q355';   % 只生成Q355
fit_target = 'both';   % 生成两种钢材对比图
model_choices = "auto"; % 使用03自动选择最优函数
formula_digits = 4;      % 公式参数显示4位小数
```

`Q370` 也可作为 `Q370NH` 的输入别名。

## 数据和计算方法

- 原始数据在 `strength_property_data.csv`。
- 每种钢材使用9个腐蚀时间、1号和2号试件，共18个散点。
- 屈服强度、抗拉强度和断裂强度由03文件夹比较9种候选函数并选择AICc最小的模型。
- 屈强比按各试件 `fu/fy` 计算，默认采用均值模型，也可以人工选择其他模型。
- CSV中 `EtaPercent` 保存百分数，回归时自动转换为 `eta=EtaPercent/100`。

程序始终根据CSV重新计算公式和R2，不会把参考图中的旧公式硬编码到程序中。完整参数保存在 `03_统一拟合结果/统一拟合结果.mat`，公式小数位只影响显示。

## 输出

程序分别生成：

- 屈服强度拟合图；
- 抗拉强度拟合图；
- 屈强比统计图；
- 断裂强度拟合图。

每张图同时输出 `.png`、`.tif`、`.pdf`和 `.fig`，并生成拟合参数CSV和绘图数据CSV。
