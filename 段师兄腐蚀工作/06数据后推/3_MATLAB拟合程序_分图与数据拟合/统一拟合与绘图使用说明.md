# 统一拟合与绘图使用说明

## 总体流程

```text
01/02/04/05/06中的实验数据
        ↓
03_通用最优拟合函数选择器
        ↓
按材料和指标分别选择最优函数
        ↓
保存统一拟合结果MAT和CSV
        ↓
各业务文件夹按原版式绘图
```

## 使用方法

进入需要绘图的文件夹，打开对应 `plot_*.m`，修改：

```matlab
fit_target = 'both';
model_choices = "auto";
formula_digits = 4;
```

- `fit_target`：选择 `Q370NH`、`Q355` 或 `both`；
- `model_choices="auto"`：按AICc自动选择最优模型；
- `model_choices="prompt"`：每种材料、每个指标分别弹窗选择模型；
- `formula_digits`：控制公式显示的小数位数，不影响计算精度。

## 分文件夹入口

- 01：`plot_Q370NH_Q355_corrosion_time.m`
- 02：`plot_separate_pit_parameter_fits.m`
- 04：`plot_strength_property_fits.m`
- 05：`plot_strain_modulus_fits.m`
- 06：`plot_pit_parameters_vs_mass_loss.m`

## 输出说明

各输出目录内的 `03_统一拟合结果` 包含：

- `统一拟合结果.mat`：完整精度参数，供曲线计算；
- `统一拟合结果.csv`：可查看的模型、P1-P4、公式和评价指标；
- 按材料和指标划分的详细拟合结果。

图内公式以及业务参数CSV使用 `formula_digits` 指定的显示位数。更改位数后曲线不会发生变化。

## 指定单独模型

也可以用结构体为不同指标指定模型，例如：

```matlab
model_choices = struct( ...
    'PitDepth',"幂函数", ...
    'AspectRatio',"对数函数");
```

强度数据示例：

```matlab
model_choices = struct( ...
    'YieldStrength',"线性函数", ...
    'TensileStrength',"幂函数", ...
    'FractureStrength',"二次函数", ...
    'StrengthRatio',"均值模型");
```
