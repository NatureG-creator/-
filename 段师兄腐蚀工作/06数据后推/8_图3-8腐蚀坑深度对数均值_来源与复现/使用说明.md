# 腐蚀坑深度对数均值程序与数据说明

本文件夹独立对应论文3.3.4.2节中的腐蚀坑深度对数均值，图3-8和表3-7。原脚本为 `shujunihe_sd.m`，位于“程序”子目录。输入数据、四组原图、论文内嵌图件、重算图及公式表均已配齐，不依赖另一个指标文件夹。

## 运行

将MATLAB当前文件夹切换到本文件夹，输入：

```matlab
run_pit_depth_fits
```

仅运行数据3：

```matlab
run_pit_depth_fits(3)
```

需要Optimization Toolbox和Statistics and Machine Learning Toolbox。四组结果分别保存在“重新计算结果/数据1”至“数据4”。入口按明确的文件和变量读取数据，并传给原程序所需的 `sd_5`；原程序保持原样。

## 查看结果

- 输入数据：第一列为质量损失率百分数数值，第二列为对应参数的对数均值。
- 四组数据_公式与来源汇总.csv：16条模型公式、完整参数和对应数据来源。
- 论文表格_逐项核对.csv：与论文表3-7的逐项比较。
- 原始图件：8张原EMF，均与论文内嵌图文件校验值一致。
- 重新计算结果：8张PNG及PDF/TIF、公式评价表和完整参数MAT。

数据1、2、3分别来自sj1.mat、sj7.mat、gq2.mat；数据4来自sj5_bare_steel_sd.mat。每组实际变量名称见公式与来源汇总表。

## 已确认的差异

64项评价指标中60项在论文显示精度内一致；差异集中在数据2的两阶段对数模型。R²：论文0.9701，重算0.9604；测试集RMSE：论文0.0916，重算0.1720。
