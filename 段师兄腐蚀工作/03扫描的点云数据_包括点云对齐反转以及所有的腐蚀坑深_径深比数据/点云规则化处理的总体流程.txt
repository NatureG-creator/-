一、点云规则化处理的总体流程

原始扫描点云通常以 X、Y、Z 三列坐标保存。由于扫描点的位置不完全规则，且试件在扫描时可能存在倾斜，因此需要先统一方向，再插值为规则网格，最后补齐缺失值。

处理流程如下：

原始离散点云
    ↓
拟合基准平面并进行初步齐平
    ↓
对 XY 方向进行 PCA 主方向分析
    ↓
旋转坐标，使试件长边与坐标轴平行
    ↓
使用 griddata 插值成规则网格
    ↓
使用最近邻方法补齐缺失值
    ↓
得到规则高度矩阵 Z_filled

二、PCA 主方向分析

1. 作用

PCA 用于确定点云在 XY 平面内的主要延伸方向。对于腐蚀试件，最长的方向通常对应试件的长边。

2. 处理方法

程序提取点云的 X、Y 坐标，计算协方差矩阵，再求协方差矩阵的特征向量。最大特征值对应的特征向量就是点云的主方向。

典型 MATLAB 代码：

xy_points = rotated_points(:,1:2);
cov_matrix = cov(xy_points);
[V,~] = eig(cov_matrix);
major_axis = V(:,2);

3. 结果含义

如果主方向向量不是 [1,0]，说明试件长边相对于 X 轴存在倾斜。程序根据该向量计算倾斜角度，为下一步旋转坐标提供依据。

三、旋转坐标，使试件长边与坐标轴平行

1. 作用

将倾斜的试件旋转到统一坐标方向，使长边尽量平行于 X 轴，短边尽量平行于 Y 轴。

2. 处理方法

程序先计算主方向与 X 轴的夹角，再使用相反角度进行二维旋转。旋转前先减去点云中心坐标，旋转后再加回点云中心，避免点云位置发生不必要的平移。

典型 MATLAB 代码：

angle_current = atan2(major_axis(2),major_axis(1));
angle_rotate = -angle_current;

R_2d = [cos(angle_rotate), -sin(angle_rotate);
        sin(angle_rotate),  cos(angle_rotate)];

rotated_xy = (xy_points - mean(xy_points)) * R_2d';
rotated_xy = rotated_xy + mean(xy_points);

3. 注意事项

旋转只改变 X、Y 平面方向，不改变腐蚀表面的实际形貌。旋转之后，点云的长宽方向会更加统一，便于后续建立规则网格和进行不同试件之间的比较。

四、使用 griddata 插值成规则网格

1. 为什么需要插值

原始扫描点是离散点，点与点之间的 X、Y 间距可能不完全一致，不能直接组成规则的高度矩阵。后续的 surf 绘图、腐蚀坑识别和 APDL 建模通常需要规则网格。

2. 建立规则网格

设置网格分辨率，例如 0.3 mm：

grid_resolution = 0.3;
x_grid = min(x_aligned):grid_resolution:max(x_aligned);
y_grid = min(y_aligned):grid_resolution:max(y_aligned);
[X,Y] = meshgrid(x_grid,y_grid);

3. 进行插值

Z = griddata(x_aligned,y_aligned,z_aligned,X,Y);

其中，x_aligned、y_aligned、z_aligned 是已经旋转后的离散点，X、Y 是规则网格坐标，Z 是规则网格上的高度矩阵。

4. 结果含义

Z(i,j) 表示规则网格位置 X(i,j)、Y(i,j) 对应的表面高度。Z 可以用于绘制腐蚀表面，也可以作为后续腐蚀坑分析的输入。

五、使用最近邻方法补齐缺失值

1. 缺失值产生原因

如果规则网格位置超出了原始扫描点的覆盖范围，或者原始扫描区域存在空洞，griddata 会将相应位置记为 NaN。

2. 补齐方法

程序可以沿行、列方向使用最近的非缺失值进行填补：

Z_filled = fillmissing(Z,'nearest',1);
Z_filled = fillmissing(Z_filled,'nearest',2);

第一句按列补齐，第二句按行补齐。

3. 结果含义

Z_filled 是补齐后的完整高度矩阵，可以用于高斯滤波、分水岭分割、腐蚀坑识别和腐蚀坑参数统计。

4. 注意事项

最近邻补齐适合处理少量边缘缺失值。如果缺失区域较大，补齐结果只是估计值，可能影响腐蚀坑深度计算。使用时应检查补齐前后的表面图，确认没有明显的异常平面或条纹。

Z_filled 后续可用于：

1. 绘制腐蚀表面；
2. 识别腐蚀坑极值点；
3. 分水岭分割各个腐蚀坑；
4. 计算腐蚀坑深度、直径和径深比；
5. 生成 APDL 所需的坐标数据。

八、结论

PCA 的作用是找出试件长边方向；旋转的作用是统一坐标方向；griddata 的作用是将不规则散点转换为规则高度矩阵；最近邻补齐的作用是填补规则网格中的缺失高度。四步共同完成从原始扫描点云到可分析、可绘图、可用于数值建模的规则腐蚀表面数据的转换。
