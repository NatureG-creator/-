# 正向深度处理与代码6使用说明

## 本次修改解决什么

修复原流程中三个混用问题：只有Z减最高值而Z_filled未减、190/50分别齐平导致不同高度基准、实测先取负而模拟用正深度。现在向内腐蚀深度为正，红色极大值点代表检测到的坑底；不是把所有数取绝对值。

原CA演化、GA十参数、分水岭阈值、极值筛选、坑径算法和直方图程序不改。实测数据会变化，因为高度基准、取坑方向和分析矩阵已经纠正，不能继续用旧目标校准。

## 直接怎么运行

1. MATLAB当前文件夹切到本目录，运行untitled。也可在代码6的主流程_只运行这里运行step01_measured.m，它转到本目录执行。
2. 程序读取配置指定的190 mm扫描，核对50 mm原始XYZ确实来自同一190扫描。50文件只作来源核对，不再独立齐平。
3. shujuguiyi对190扫描齐平、PCA、插值、补洞、裁边一次，Z与Z_filled保留同一高程基准。单独调用这个函数得到的是齐平高程，不是自动减参考面的深度。
4. prepare_positive_corrosion_surface调用jisuan_190：前200列作参考，中央168列作腐蚀段，D=中央高程-H_flat。平滑中央段一次后识别峰点和坑边界。
5. 结果进入本目录新建的正向深度结果_时间戳目录，包括矩阵MAT、坑深Excel及原图；红点图另外明确命名为红点极值与等高线.png。旧结果不覆盖。
6. export_original_ca_target生成代码6/01_实测目标接口/实测目标/原程序目标_时间戳/matlab_target.mat。latest_original_target.txt指向最新导出。
7. Python编辑器运行代码6/主流程_只运行这里/step02_ca_ga.py。它用实测目标进行种群CA-GA，不是固定十参数直接模拟。然后step03_images.py绘图分析，step04_fracture.py进入已有断裂接口。

## 指标对应

所有表面统计使用同一平滑D矩阵，单位mm；导出给Python的长度单位为μm。

| 指标 | 定义 | C17本次结果 |
|---|---|---:|
| 均匀腐蚀分量 | min(D)，本程序定义为最浅腐蚀深度 | 110.201954 μm |
| 不均匀腐蚀深度 | mean(D-min(D)) | 259.768757 μm |
| 平均总腐蚀深度 | mean(D)=均匀分量+不均匀分量 | 369.970711 μm |
| 径深比对数均值 | mean(ln(直径/局部坑深)) | 2.052908704 |
| 坑深对数均值 | mean(ln(局部坑深/1 μm)) | 5.826931534 |
| 径深比对数标准差 | std(ln(直径/坑深),0)，样本标准差 | 0.699307782 |
| 坑深对数标准差 | std(ln(坑深/1 μm),0) | 0.198752906 |

六目标顺序为：[平均总深度μm，不均匀深度μm，径深比对数均值，坑深对数均值，两项对数样本标准差]。均匀分量另存，不是第一项；平均局部坑深也不是均匀分量。

坑深仍按原fushikengtiqu规则：检测峰点D减全表面min(D)。它是局部起伏深度，不是峰点距未腐蚀参考面的总深度，也不是逐坑边缘拟合的坑深。sjb=坑深/直径；径深比=1/sjb。没有悄悄换成新的坑缘算法。

本次识别15个有效坑，平均局部坑深345.8384 μm。原始未平滑最小深度43.888155 μm，平滑后最小为110.201954 μm：两者不同是高斯滤波抬高局部谷值造成，不应混用。模拟也用同样滤波后统计。

## 参考面与图形

H_flat仍采用原定义min(参考区)+0.2*(max-min)，不是20%分位数。中央168列的格点跨度为167×0.3=50.1 mm，裁边后宽度18 mm，矩阵61×168。绘图用真实毫米，不照参考图片把试件放大成100×150 mm。

三维表面保持原配色、视角、红点，向上峰对应更深腐蚀。红点只标记原算法筛出的极大值，不承诺边缘每一个峰都被识别。等高图保留分水岭红边界。实际深度范围约0.1102～0.6284 mm，不强制伪装成示意图的0.1～0.5 mm。

分水岭六面板诊断图仍保留。其三维红边界现在采用mm坐标并落在真实深度表面，不再把二值掩码1误画成1 mm深度；前五个二维诊断子图仍是像素图，不用于尺寸量测。

参考区是否真正未腐蚀、是否适合单一水平参考，仍需实验核对。这套统计中min(D)是程序约定的均匀分量，不等于已独立测定的物理均匀腐蚀量。正值和接口通过不能单独证明参考面正确。

## 可自行调整

- MATLAB输入路径、网格0.3 mm、裁边3、高斯sigma=2、参考200列/0.2、中央168列：step00_corrosion_config.m。修改后必须重跑untitled导出目标。
- 主高斯sigma=0可关闭主平滑；实测和模拟均支持同一分支。分水岭内部sigma=0.5用于梯度识别，是另一项，不会把其平滑矩阵用于六指标统计。
- 坑阈值0.001 mm、间隔15格、邻域12×12、分水岭0.3：同一配置。间隔15格等于4.5 mm；改阈值会改变坑数量，不是增加实验样本。
- Python种群、代数、每个候选CA步数、深度元胞25 μm、10进程：代码6/09_共享模拟内核与指标/unified_config.py。横向间距300 μm必须与MATLAB一致，实测校准矩阵尺寸自动读取。
- 若改变MATLAB识别参数，Python ANALYSIS_CONFIG要对应修改。程序会检查，不自动换一套算法。
- 原参考面导致负深度时保留诊断并拒绝校准；不能自行abs、加常数或删点只为把结果变正。先确认Z方向和参考区。
