# 高程、正向相对深度与未腐蚀参考面

## 如何运行

在MATLAB打开本目录，运行 `untitled.m`。参数仍在 `step00_corrosion_config.m` 中。
原扫描TXT、统一参数前备份和旧结果未覆盖。修改前程序另存于 `高程与相对深度修复前备份_20261009_163107`。

## 三者分别是什么

| 量 | 变量及公式 | 作用 |
|---|---|---|
| 齐平高程 | `H_raw`（补洞后）、`H`/`Z_filled`（平滑后） | 保留原50 mm高程；低处为本流程识别的坑底 |
| 检测矩阵 | `-H` | 沿用原极大值检测、分水岭、坑径规则；红点对应H的低处 |
| 正向相对深度 | `display_depth_mm=max(H)-H` | 只将检测矩阵整体平移，坑越深显示越高；零点是当前表面最高点 |
| 未腐蚀参考面 | 同一坐标基准、已确认物理方向的 `H0` | 只有确认它，才能计算总损失；不能拿独立齐平190 mm的高度直接作为50 mm的H0 |
| 不均匀深度 | `max(H)-mean(H)` | 对应示意图的顶点至平均线距离 |
| 均匀分量 | `H0-max(H)` | 对应原始未腐蚀面至表面顶点距离 |
| 平均总深度 | `H0-mean(H)` | 均匀分量+不均匀深度，不等于平均坑深 |
| 单坑深度 | `max(H)-H(坑底)` | 保留原全局顶点到坑底定义，不擅自改为局部坑缘到坑底 |

`jixiantiqu_3D`新增第六参数仅用于显示矩阵，所有数值检测仍用第一参数。`fenshuiling_boundry`新增第五参数仅用于图像显示平移，分割计算不变。
相对深度为正只说明绘图零点设置，不能证明扫描物理方向或参考面正确。这里恢复的是原高程坑底识别，不冒称已经完成物理方向标定。

## 190 mm参考面怎么处理

190 mm仍按原程序独立齐平，参考高度为左200列 `min+0.2*(max-min)`，中央168列取最高高程。
保留有符号诊断 `uniform_190_diagnostic_mm=H_flat-H_corroded`。
真实C17结果为约−0.696670 mm，不取绝对值、不自动改方向。
来自同一原始扫描的子集在分别拟合平面、旋转、插值后，高度并不自动同基准，不能直接拼接。

## 导出和CA-GA

按用户要求，当前主程序恢复旧程序统计：`junyunfushi` 使用190 mm旧公式并保留有符号值，`avg_total_depth_mm` 变量恢复为旧程序的平均坑深统计。它们可以正常打印；但二者不能被误称为同一50 mm总深度基准。
新MAT保存高程、正向相对深度、16个原坑样本、五项可确定指标及190 mm诊断。
代码6接口仍使用 `original_matlab_height_relative_v3`，`calibration_ready=false`，因为导出的相对矩阵与旧190 mm参考值不是同一高度基准。
`relative_depth_um` 是相对显示；绝对 `depth_um`、`processed_depth_um` 明确为NaN，不让后端误用。
Python会阻止把此诊断目标交给完整六指标CA-GA。CA/GA模拟内核没有修改，固定参数模拟仍与本次变更无关。

恢复完整六指标校准前，需要先确认未腐蚀参考区与物理方向，并让参考区和50 mm数据使用同一已核验的坐标变换/高度基准，或提供独立实测均匀损失并明确来源。不能仅把NaN填成正数或翻转高度来绕过检查。
