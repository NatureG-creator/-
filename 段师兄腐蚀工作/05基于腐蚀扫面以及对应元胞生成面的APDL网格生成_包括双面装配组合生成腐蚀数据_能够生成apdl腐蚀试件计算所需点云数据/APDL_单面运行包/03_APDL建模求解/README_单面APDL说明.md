# 单面 APDL 建模求解目录

本目录预留给只使用一个腐蚀表面的 APDL 命令流。

单面 MATLAB 程序生成：

```text
../02_坐标文件/DIANYUN_X.txt
../02_坐标文件/DIANYUN_Y.txt
../02_坐标文件/DIANYUN_Z.txt
```

当前原始项目中没有发现与这三个文件配套的独立单面 APDL 求解命令流。现有 `model3` 命令流读取正反面坐标，属于双面模型，不能直接作为单面模型使用。单面 MATLAB 程序和原始配置版已经整理在 `01_MATLAB预处理` 中。

单面 APDL 命令流至少需要明确：

1. 单面表面是上表面还是下表面；
2. 另一侧是平面、固定厚度还是另一个腐蚀面；
3. `nx`、`ny`、`dx`、`dy` 和厚度层数；
4. 边界条件、加载方式和结果输出位置。
