# APDL 推荐运行包设计

## 目标
在不覆盖现有文件的前提下，建立一个独立的 APDL 推荐运行包。该运行包集中保存全部 MAT 输入数据，同时用一组尺寸匹配的 `60×193` 数据作为默认示例，形成清晰的 MATLAB 预处理—APDL 建模—非线性静力求解—力位移后处理链路。

## 目录设计

```text
APDL_推荐运行包/
├─ 00_输入数据/                 # 全部 MAT 数据，保留原有 C、NH、元胞自动机目录层级
├─ 01_MATLAB预处理/             # 默认运行驱动和双面坐标生成脚本
├─ 02_坐标文件/                 # MATLAB 生成的六个 DIANYUN_*.txt
├─ 03_APDL建模求解/              # model3 修正版 APDL 主命令流
├─ 04_结果/                     # APDL 输出的力—位移文本和运行日志
└─ README_运行说明.md            # 运行顺序、变量要求、尺寸规则和验证边界
```

## 主运行链

默认数据为 `C/C17_100D/60/Z60193.mat` 与 `C/C17_100D/60/F.mat`，二者均为 `60×193`，对应 `model3` 的 `nx=193`、`ny=60`。MATLAB 驱动脚本负责加载变量、切换到 `02_坐标文件`、调用双面预处理脚本并生成六个坐标文件。APDL 主命令流从该目录读取坐标，生成 9 个节点面和 8 层 `SOLID185` 实体单元，施加原有边界条件和右端位移 `UX=11`，再在 `/POST1` 中累计加载边的 `RF,FX` 并写出力—位移数据。

## 兼容性边界

- 只有正反面矩阵尺寸一致的数据可以直接进入双面预处理。
- 当前 APDL 主命令流固定为 `nx=193`、`ny=60`；其他尺寸的数据必须先裁剪/重采样并同步修改 APDL 参数。
- `model2`、单面导出脚本和扩展加持脚本归入参考区或明确标记，不作为默认运行链。
- 原始目录不修改；新目录中的文件为副本或新建驱动/说明文件。

## 验证

整理后执行静态检查：确认全部 MAT 文件已复制、默认数据变量和尺寸正确、MATLAB 输出文件名与 APDL `*VREAD` 名称一致、APDL 参数/节点数/单元数/加载位置一致。当前环境不承诺 MAPDL 实际求解、收敛和许可证验证，README 中明确这一点。
